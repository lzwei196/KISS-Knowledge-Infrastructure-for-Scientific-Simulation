# Stage 4: Meteorological Forcing Preparation

## Purpose
Convert gridded meteorological data (CMFD, MSWX, ERA5) into GSFLOW's PRMS input
format — either a `.data` file with station observations or `.day` files with
pre-processed per-HRU values.

## Inputs
- Gridded forcing NetCDF files (one per variable per year):
  - CMFD: `prec_CMFD_*.nc`, `temp_CMFD_*.nc`, `srad_CMFD_*.nc`, etc.
  - MSWX: `Tair_*.nc`, `P_*.nc`, `SWd_*.nc`, etc.
- Basin shapefile (for spatial subsetting and area-averaging)
- HRU definitions (for distributed forcing)
- Target units configuration

## Outputs
- For `climate_hru` module: `.day` files (one per variable)
  - `tmax.day`, `tmin.day`, `precip.day`, `swrad.day`, `potet.day` (optional)
- For station modules: `.data` file with station time series

## Procedure

1. **Identify grid cells within basin:**
   ```python
   basin = gpd.read_file("basin.shp")
   # Find CMFD grid cells that intersect basin polygon
   cells = find_cells_in_basin(basin, cmfd_lats, cmfd_lons)
   ```

2. **Extract and convert temperature:**
   - CMFD: daily mean in Kelvin
   - GSFLOW needs tmax and tmin
   - If only mean temperature available: approximate tmax = T + 5°C, tmin = T - 5°C
   - Convert: K → °F: `(K - 273.15) × 9/5 + 32` (if temp_units=0)
   - Convert: K → °C: `K - 273.15` (if temp_units=1)

3. **Extract and convert precipitation:**
   - CMFD: mm/day
   - Convert: mm → inches: `mm × 0.03937` (if precip_units=0)
   - No conversion needed if precip_units=1 (mm)
   - Ensure non-negative values

4. **Extract and convert solar radiation:**
   - CMFD: W/m²
   - GSFLOW expects Langleys/day (cal/cm²/day)
   - Convert: `W/m² × 2.065` (= 86400 / 41868)
   - Ensure non-negative (clip nighttime interpolation artifacts)

5. **Write .day files:**
   ```
   tmax.day generated by convert_forcing_to_gsflow
   ########################################
   1980 1 1 0 0 0  55.2  54.8  53.1  ...  (nhru values)
   1980 1 2 0 0 0  57.1  56.3  55.0  ...
   ```

6. **Update control file** to reference .day files:
   ```
   tmax_day → ./input/prms/tmax.day
   tmin_day → ./input/prms/tmin.day
   precip_day → ./input/prms/precip.day
   swrad_day → ./input/prms/swrad.day
   ```

## Verification
- File line count = n_days + 2 (header + delimiter + data)
- Each data line has `6 + nhru` columns (date + values)
- Temperature range: -50 to 130°F (-45 to 55°C)
- Precipitation: all values ≥ 0
- Solar radiation: all values ≥ 0, max < 1000 Langleys (~500 W/m²)
- No missing values (GSFLOW uses -99 as missing flag, which causes errors)
- Total annual precipitation is physically reasonable (500–2000 mm for most basins)

## Traps

### CRITICAL: Unit Conversion Errors (Silent Failures)

| Source | Variable | Source Unit | GSFLOW Unit | Factor | Error if Skipped |
|--------|----------|------------|-------------|--------|-----------------|
| CMFD | Temperature | K | °F | (K-273.15)×9/5+32 | Snow model fails |
| CMFD | Temperature | K | °C | K-273.15 | Snow model fails |
| CMFD | Precipitation | mm/day | inches/day | ×0.03937 | 25× too much precip |
| CMFD | Solar radiation | W/m² | Langleys/day | ×2.065 | 2× ET error |
| MSWX | Temperature | K | °F | Same as CMFD | Same as CMFD |
| MSWX | Precipitation | mm/3hr | inches/day | ×8×0.03937 | Accumulation error |

### Other Traps
- **Missing HRU values:** Each .day line must have exactly nhru values.
  Fewer values → runtime crash. More → values silently ignored.
- **Date continuity:** .day files must be continuous (no gaps).
  Missing days → date mismatch → wrong forcing applied to wrong day.
- **Leap years:** Some gridded datasets handle Feb 29 differently.
  Verify .day files include leap days for leap years.
- **Header format:** First line is free text, second line must be `#`×40.
  Wrong header → data parsed as header → shifted time series.
- **Temperature range check:** PRMS has internal range check (-150 to 200°F).
  If temp_units=0 (°F) but you provide °C data, values will pass range check
  but give wrong results (e.g., 25°C treated as 25°F → everything freezes).

## Example
```bash
python convert_forcing_to_gsflow.py \
    --forcing-dir /mnt/disk1/Hydrocraft_server/data/forcing/huai/Data_forcing_01dy_025deg/ \
    --shapefile /mnt/disk1/Hydrocraft_server/data/shp/bengbu_shp/bengbu_clip.shp \
    --output-dir ./input/prms/ \
    --start-year 1980 --end-year 1990 \
    --source cmfd \
    --temp-units celsius --precip-units mm \
    --n-hru 1
```
