# 已测试示例：恢复 SHAW 参考参数

这个 Windows 基准通过 KI 工具和统一校准引擎，反复执行真正的 SHAW 3.03 原生程序，检查优化能否从发布者的参考结果中恢复已知参数。

> **范围：** 目标是官方模型参考输出，不是实地测量。结果检验参数写入、原生运行、评分及留出处理，不能作为模型对观测数据的表现来引用。

## 可复现配置

使用三页快速指南列出的五个 SHAW Trial 输入，以及 [SHAW 3.03 官方压缩包](https://www.ars.usda.gov/ARSUserFiles/20520500/SHAW/303/Shaw303.zip) 中的温度参考表。参考文件位于压缩包内的 `Shaw303/Output/Trial/temp.out`。保留原始文件；项目适配器为每次评估生成独立的候选输入。

| 设置 | 实测采用的值 |
|---|---|
| 参数 | 对全部 11 个土壤节点应用 `bulk_density_scale` |
| 范围 | 0.8 至 1.5 |
| 人为扰动的基线 | 1.3 |
| 已知参考值 | 1.0 |
| 方法 / 种子 / 搜索预算 | DDS / 20261002 / 请求 60 次优化器评估 |
| 训练数据 | 155 个逐小时记录 × 11 节点；1986-12-04 13:00 至 1986-12-10 23:00 |
| 留出数据 | 145 个逐小时记录 × 11 节点；1986-12-11 00:00 至 1986-12-17 00:00 |
| 指标 | NSE 和温度 RMSE（°C），不使用摄氏温度 PBIAS |

这些范围与人为基线只用于**软件参考恢复测试**，不是野外土壤密度估计的建议。其他 Trial 参数和驱动保持固定。

## 真实结果

拟合倍率为 **1.003065603**。训练 NSE 为 **0.99998413**，RMSE 为 **0.011098 °C**。留出 NSE 从扰动基线的 **0.98713640** 提高到 **0.99998794**。已配置的留出检查通过，引擎在本基准范围内将结果标记为可采用。

统一引擎固定在修订 `579162102f71f2fa4619b874a21bd219caaed25e`。适配器属于项目，位于 `calibration/kis/SHAW/calibration.yaml` 和 `tools/calib_run.py`，并不因此宣称有适用于所有 SHAW 研究的通用适配器。完整证据保存在测试项目及验证机器上的 `D:/GeoForge-Calibration-20261002/native-calibration-result.json`。

源码与打包后的 Windows 引擎得到相同拟合结果。包含探测、基线和留出检查在内，测试实际调用原生模型 64 次。另一次已知参数值 1.0 的运行与发布者的温度输出逐字节一致。六种优化算法也都通过了合成函数接口测试；这些合成测试不能证明科学预测能力。
