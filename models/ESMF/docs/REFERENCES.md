## Related Software

- **NUOPC**: National Unified Operational Prediction Capability (coupling layer built on ESMF)
- **ESMX**: Earth System Model eXecutable (YAML-driven coupled model driver)
- **MAPL**: NASA GMAO's mid-layer built on ESMF
- **CESM/CIME**: Community Earth System Model uses ESMF/NUOPC for coupling
- **UFS**: Unified Forecast System (NOAA) built on ESMF/NUOPC
