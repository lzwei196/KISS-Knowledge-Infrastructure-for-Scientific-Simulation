## Related Models and Data

- **MOSART (Fortran)**: Original Fortran implementation in CESM/E3SM
  - https://github.com/E3SM-Project/E3SM (river routing component)
- **GRanD Database**: Global Reservoir and Dam Database used for reservoir parameters
  - https://www.globaldamwatch.org/grand/
- **NLDAS-2**: North American Land Data Assimilation System (common forcing source)
  - https://ldas.gsfc.nasa.gov/nldas/
- **CLM/VIC**: Land surface models providing runoff forcing input
  - CLM: https://www.cesm.ucar.edu/models/clm/
  - VIC: https://vic.readthedocs.io/
