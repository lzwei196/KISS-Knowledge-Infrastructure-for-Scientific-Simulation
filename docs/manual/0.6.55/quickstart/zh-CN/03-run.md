# 3 批准运行并核对结果

**目标：** 用真实模型复现发布者的 SHAW Trial。这是官方示例的正向检验，不是利用实测观测进行校准。

## 发送这个请求

> 请用我上传的五个原始文件运行 SHAW 3.03 官方 Trial。保留全部科学输入和控制选项。将输入准备到本项目，用 KI 工具运行本机原生 SHAW，导出 CSV 并绘制土壤剖面。不用 GeoForge 数据库，不生成驱动，不校准参数。报告实际行数和时段；核对温度和含水量各 301 行、液态水 14 行、能量 300 行、水量 13 行、冻土 48 行，结束于 1986-12-17 00:00。

## 先审阅，再运行

1. 逐一回答规划卡片，用卡片上的按钮保存选择。
2. 在 **Approve the plan?**（是否批准计划）中检查：只用 SHAW；输入是五个真实文件；**运行 → 解析 → 作图** 均有可执行工具。确认输出位置，且没有提出校准。
3. 不符合时选 **Modify the plan**（修改计划）；符合时选 **Approve and start**（批准并开始），再点击 **Continue with this choice**（按此选择继续）。只批准眼前这份具体计划。
4. 保持应用运行。打开 **◇ 项目状态** 查看配置、执行和检查。计划或工具发生变化时可能需要重新审阅，原批准不会自动涵盖变化。

## 已验证的示例结果

| 原始结果表 | 行数 | 核对内容 |
|---|---:|---|
| 温度 / 含水量 | 各 301 | 11 个土壤节点 |
| 液态水 / 能量 | 14 / 300 | 完整参考时段 |
| 水量平衡 / 冻土 | 13 / 48 | 物理列和单位正确 |

六张表均结束于 **1986-12-17 00:00**；初始温度和含水量剖面从 **1986-12-04 12:00** 开始。本次真实运行在输出的打印精度上与官方数值一致，另有五个 CSV 和真实绘图。

**完成检查：** GeoForge 必须显示 **已完成**，三个步骤都要有通过的运行记录。到 **结果** 打开 CSV 和图。AI 说成功、目录里有旧文件，或运行记录仍是警告/失败，都不等于完成。请 Agent 修复并重新运行受影响的已批准步骤，不要删除自己的输入。

需要校准时，打开 **使用指南 → 参数校准指南**；其他流程和排错看 **完整使用手册**。两个指南都能从同一菜单离线阅读。
