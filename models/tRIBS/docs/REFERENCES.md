## Related Software
- **CHILD** (Channel-Hillslope Integrated Landscape Development) — landscape evolution model using similar TIN framework
- **tRIBS-VEGGIE** — coupled ecohydrological extension of tRIBS

## Data Sources Referenced
- **CMFD** (China Meteorological Forcing Dataset) — used in Wangjiaba/Bengbu validation
- **ERA5** — ECMWF reanalysis, common forcing source
- **HWSD** (Harmonized World Soil Database) — soil parameters
- **SSURGO** (Soil Survey Geographic Database) — US soil parameters
