# 2 配置 SHAW，准备五个输入

**目标：** 安装真正的科学模型程序。SHAW KI 提供说明和工具；选中 KI 不等于已经安装模型。

## 安装并验证 SHAW

1. 打开 **KI 库**，搜索 `SHAW`，点击搜索结果，选择 **DeepSeek (API)**，点击 **使用 Agent 设置**。已验证时，点击 **打开设置与验证**。
2. 在 **Agent 设置** 中选择 **安装或编译新的副本**。使用可写文件夹，例如 `D:\GeoForge\models\SHAW`；修改后点击 **使用此位置**。
3. 选择 `deepseek-chat`，点击 **开始 Agent 设置**，按 **需要你** 中的要求操作。等待 GeoForge 最终验证；若失败，先读 **验证**，再点击 **继续修复**。

![真实应用中的 SHAW 软件设置与验证](../../images/zh-CN/quickstart-02-ki.png){: .ki-shot }

*已有安装显示 **让 Agent 重新检查**。遇到缺失依赖时，安装可能需要协助。*

## 下载并附上官方输入

4. 下载 USDA-ARS 的 [官方 Shaw303.zip](https://www.ars.usda.gov/ARSUserFiles/20520500/SHAW/303/Shaw303.zip)。从其中的 **`Shaw303/` 文件夹提取这五个文件**，保留原文件名和内容：

| 文件 | 内容 |
|---|---|
| `Trial.303.inp` | 运行控制选项 |
| `Trial.30.sit` | 场地与土壤参数 |
| `Trial.30.wea` | 气象驱动 |
| `Trial.moi` / `Trial.tem` | 初始含水量 / 初始温度 |

5. 回到 `SHAW official Trial` 对话。点击 **＋ 文件**，附上全部五个文件。若规划卡片要求提供输入，请通过对应的 **上传文件** 行把文件关联到计划。

**预期结果：** 验证通过，五个原始输入已附上。不要把 `Output/Trial/` 参考结果当作输入。
