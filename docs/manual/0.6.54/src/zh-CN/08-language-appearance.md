# 8 语言、外观和键盘

本章介绍如何在英文和简体中文之间切换 GeoForge 的界面，如何选择浅色或深色外观，以及 GeoForge 会响应的几个按键。

## 切换界面语言

GeoForge 有两种界面语言：英文和简体中文。语言按钮在侧边栏底部，**设置** 按钮的右边。按钮上显示的总是你要切换*到*的语言：界面是英文时显示 **简体中文**，界面是中文时显示 **English**。

1. 先把消息输入框里已经输入但还没发送的内容发出去，或者复制下来。下一步会重新加载页面，未发送的文字和这条消息附加的文件列表都会被清空。已经添加的文件仍保存在项目文件夹中。
2. 在侧边栏底部，点击 **简体中文**。

    ![英文界面的主窗口，侧边栏底部有“简体中文”按钮](../../images/en/11-chat-empty.png)

    此时界面还是英文，**设置** 按钮显示为 **Settings**。确认 **简体中文** 在 **Settings** 的右边，**◐** 按钮在 **Settings** 的下一行。

3. 等待页面重新加载。现在按钮、面板标题和提示都是中文了。

    ![切换到中文后的同一窗口](../../images/zh-CN/11-chat-empty.png)

    确认侧边栏按钮现在显示 **English**，**Send** 变成了 **发送**。对话名称、服务商 *DeepSeek (API)* 和模型 *deepseek-chat* 都不变。

4. 要切回英文，在同一位置点击 **English**。页面会重新加载为英文。

每次重新加载后，GeoForge 都会打开对话列表最上面的那个对话。如果你之前在用别的对话，在列表中点击它即可。

每个 GeoForge 页面都有语言按钮：主窗口、**KI 库**、**KI 工作室**、**KI 观测台** 和 **Agent 设置**。在任一页面切换一次，所有页面都会使用这种语言。已经在其他标签页中打开的页面，要重新加载后才会换成新语言。

### 首次启动时的语言

如果 GeoForge 还没有保存过语言选择，它会使用浏览器报告的语言。在 Windows 上，这就是默认浏览器的语言设置。只要是中文（包括繁体中文），就会打开简体中文界面；其他语言都打开英文界面。

在 macOS 上，即使系统是中文，GeoForge 窗口也可能以英文打开。遇到这种情况，点击 **简体中文** 即可。

### 用中文写消息会切换界面

只要你发送的消息里有一个汉字，界面就会立即切换成中文，不需要重新加载。即使一句英文里只有一个中文地名也会这样，例如 "Run FSM2 for 淮河"。

AI 也会收到相应的指令。GeoForge 要求 AI 用你最近一条消息的语言回复。如果这条消息含有汉字，GeoForge 会要求 AI 全部用简体中文回复，包括图表标题、图注和坐标轴标签。同时要求 AI 让命令、代码、文件路径、KI 名称和科学标识符保持原样。

要切回英文：

1. 点击侧边栏底部的 **English**。页面会重新加载为英文。
2. 下一条消息不要包含任何汉字。这样 GeoForge 就会要求 AI 用英文回复。

> **提示：** 如果想一直使用英文，地名请用英文或拼音书写（例如 *Huai River*、*Bengbu*）。GeoForge 数据库的搜索框按目录中的英文文字匹配，所以用英文名称和数据集 ID 能找到用中文名称找不到的数据。参见第 3 章“GeoForge 数据库”。

## 中文模式下仍显示英文的内容

中文界面会翻译 GeoForge 自身的大部分按钮、菜单、面板标题、对话框和提示。以下内容 GeoForge 从不翻译：

- 模型名称、KI 名称、文件和文件夹路径、命令和单位；
- 对话和项目名称，按你输入时的原样显示；
- AI 的消息，语言跟随你最近一条消息；
- 原始技术输出，例如灰色框里的日志和报告。

有些界面在中文模式下也会显示英文，下表列出了你会遇到的情况。括号中的中文只是说明意思，界面上不会显示。

| 位置 | 你会看到的英文 |
|---|---|
| 计划审批卡片 | 标题 **Approve the plan?**（是否批准计划？），选项 **Approve and start**（批准并开始）和 **Modify the plan**（修改计划） |
| 对话中的数据卡片 | **Download N datasets from Baidu Pan**（从百度网盘下载 N 个数据集）、**Some approved data could not be fetched**（部分已批准的数据未能获取）、**Retry the missing data**（重新获取缺失的数据） |
| **项目状态** 摘要和数据标签 | “Completed — every step has a verified receipt”（已完成，每一步都有经过验证的运行记录）、“Stopped by you — send a message to continue”（已被你停止，发送消息即可继续）、“Data needs attention”（数据需要处理） |
| GeoForge 在对话中发出的消息 | “Software verified. Starting your approved plan in a new session…”（软件已验证，正在新会话中开始执行你批准的计划） |
| 对话上方的横幅 | “Connect an AI to begin.”（请先连接 AI）和“… is not verified on this machine”（……尚未在本机验证） |
| 对话列表 | 每个对话名称下面的那一行，例如“Auto KI · 0 messages”（自动选择 KI · 0 条消息） |
| 文本框中的右键菜单 | **Cut**（剪切）、**Paste**（粘贴）和 **Select All**（全选）；**复制** 已翻译成中文 |
| **设置 → AI 服务** | 点击 **测试 AI 与 GitHub** 后显示的报告（按钮本身是中文） |
| **设置 → GeoForge 数据库** | 关于 Token、配额或网络的错误信息 |
| Windows 安装程序 | 安装向导的每一页 |
| Windows 系统托盘菜单 | **Open GeoForge**（打开 GeoForge）和 **Exit GeoForge**（退出 GeoForge） |

审批卡片和数据卡片在两种语言下的用法完全相同。第 5 章“你的第一个项目”会逐一说明各个选项。

## 选择浅色或深色外观

1. 在侧边栏底部，点击 **◐**。窗口会立即在浅色和深色之间切换，不需要重新加载。
2. 要切换回来，再点一次 **◐**。

> **[待补充截图]** 深色模式下的主窗口：与 `11-chat-empty.png` 相同的对话（*Alptal snow example*，选中 **API**，**DeepSeek (API)**，**自动选择 KI**），点击一次 **◐** 之后的样子，侧边栏底部能看到 **◐** 按钮。

确认侧边栏、对话区和消息输入框都变成了深色。主题只改变屏幕上的颜色，不影响项目文件夹中的图件和文件。

在你点击 **◐** 之前，每个页面都跟随电脑的浅色或深色设置；如果你在浏览器里单独设置过，则跟随浏览器。你的选择对主窗口、**KI 库**、**KI 观测台** 和 **Agent 设置** 都有效。

**KI 工作室** 有自己的 **◐** 按钮和单独的设置。不管其他页面是什么外观，它都以浅色打开，直到你点击它自己的 **◐**。

## 键盘

除了浏览器的常用按键（Tab 在控件之间移动；Enter 或空格键按下当前选中的按钮），GeoForge 只响应下表中的按键。新建对话、切换对话和停止运行都没有快捷键。旧版手册中提到的 Command-K 快捷键并不存在。

| 按键 | 位置 | 作用 |
|---|---|---|
| Enter | 消息输入框 | 发送消息，和点击 **发送** 一样 |
| Shift+Enter | 消息输入框 | 换行，不发送 |
| Enter | **新建项目对话** 对话框中的 **项目名称** | 创建对话，和点击 **创建对话** 一样 |
| Enter | **项目状态 → 更多细节** 中的 **GeoForge 数据库** 搜索框 | 开始搜索，和点击 **搜索** 一样 |
| Enter 或空格键 | 在 **KI 观测台** 中用 Tab 键移到的领域或 KI | 打开它，和点击一样 |
| Esc | 主窗口中的对话框（**设置**、**新建项目对话**、**本对话使用的知识基础设施**、**本对话使用的技能**、**MCP 连接**、**GeoForge 如何工作**、问题卡片），或 **KI 库** 中的对话框 | 关闭对话框。Esc 不会关闭 **项目状态** 和 **项目视图** 面板。 |
| Ctrl+C、Ctrl+X、Ctrl+V、Ctrl+A（macOS 上用 Command） | 文本框和选中的文字 | 复制、剪切、粘贴、全选 |

要复制一整条对话消息，点击发送者名字那一行上的 **复制**。在文本框中点右键，会弹出一个小菜单，包含 **Cut**、**复制**、**Paste** 和 **Select All**。在其他地方选中文字后点右键，只显示 **复制** 和 **Select All**。

> **注意：** 按 Esc、点击 ✕ 或 **暂不处理**，或者点击问题卡片外面，都会关闭卡片，但不会提交回答。计划审批卡片也是一种问题卡片。在当前页面上，卡片不会自己再出现。要回答它，打开 **项目状态** 并点击 **回答这个问题**，或者重新加载页面后再打开那个对话。

> **提示：** 使用中文输入法时，**项目名称** 输入框会忽略用来确认候选词的 Enter，所以不会在名称只输入一半时就创建对话。消息输入框没有这项检查，在某些输入法下，这个 Enter 可能会直接把消息发出去。在消息输入框里请用空格键或数字键确认候选词，只在要发送时才按 Enter。

## 重启后的偏好设置

GeoForge 把三项偏好保存在浏览器里，并且和页面地址绑定：界面语言、主题，以及 **AI 连接** 下的 **本地** | **API** 开关。GeoForge 每次启动都会使用一个新的本地地址，例如 `http://127.0.0.1:52814/`。浏览器把新地址当作一个新网站，所以这三项偏好会恢复为默认值。

| 偏好 | 重启后的默认值 |
|---|---|
| 语言 | 浏览器报告的语言 |
| 主题 | 电脑或浏览器的浅色或深色设置（**KI 工作室**：浅色） |
| **本地** \| **API** | 打开的那个对话所用的 AI 类型；如果这个对话还没有 AI，则为 **本地** |

| 平台 | 会发生什么 |
|---|---|
| Windows | GeoForge 每次启动都在默认浏览器中以新地址打开，所以三项偏好每次都会恢复默认。同一次启动期间它们会保留，包括重新加载页面，或者通过托盘 → **Open GeoForge** 重新打开页面。 |
| macOS | GeoForge 在自己的窗口中打开，每次启动也会使用新的本地地址。偏好同样会恢复默认。 |

对话、项目、API 密钥和其他 **设置** 由 GeoForge 自己保存，不放在浏览器里。重启后它们都会保留。

> **提示：** 如果你只使用 API 密钥（例如 DeepSeek），新启动后可能会看到英文提示“No local agent CLI is installed. Open AI 设置 for setup details.”（未安装本地 Agent CLI，请打开 AI 设置查看配置说明）。“AI 设置”是 **设置 → AI 服务** 的旧名称。点击 **AI 连接** 下的 **API**，或者打开一个已经在用你的 API 服务商的对话。参见第 2 章“连接 AI”。

因为地址会变，GeoForge 的书签在重启后就失效了。在 Windows 上，GeoForge 运行期间请通过托盘 → **Open GeoForge** 重新打开页面。如果已经退出，请从“开始”菜单重新启动。参见第 1 章“安装与首次启动”。

## 如果出现问题

| 你看到的情况 | 处理方法 |
|---|---|
| 界面自己切换成了中文。 | 你发送的消息里有汉字，或者浏览器语言是中文。点击侧边栏底部的 **English**。 |
| AI 一直用中文回复。 | 你最近一条消息含有汉字。下一条消息不要写任何汉字，GeoForge 就会要求 AI 用英文回复。 |
| 切换语言后，正在输入的消息不见了。 | 语言按钮会重新加载页面，未发送的文字和附件列表都会被清空。请重新输入。已经添加的文件仍在项目文件夹中。下次切换语言前，先发送或复制文字。 |
| 切换语言后，显示的是另一个对话。 | 重新加载后会打开对话列表最上面的对话。在列表中点击你的对话。 |
| 重启后，语言、主题或 **本地** \| **API** 恢复成了默认值。 | 这是正常现象，因为每次启动的地址都不同。重新设置即可。 |
| 按 Esc 后，问题卡片或审批卡片不见了。 | Esc 会关闭卡片，但不会提交回答。打开 **项目状态** 并点击 **回答这个问题**。 |
| 中文模式下的界面显示英文，例如 **Approve the plan?** | 这是正常现象。参见“中文模式下仍显示英文的内容”一节中的表格。 |
| 其他页面是深色，**KI 工作室** 仍是浅色。 | **KI 工作室** 有单独的设置。在 **KI 工作室** 中点击 **◐**。 |
| 还没写完，按 Enter 就把消息发出去了。 | 换行请用 Shift+Enter。使用中文输入法时，用空格键或数字键确认候选词。 |
