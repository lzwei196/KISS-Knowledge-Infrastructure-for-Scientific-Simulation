# s3 Model Configuration

## Purpose

Assemble the run-specific configuration that is not generated by a standalone tool: basin area, latitude, mode, calibration dates, spinup handling, and paths to the forcing and parameter files. In this KI, configuration is represented by command-line arguments to `tools/run_kineros2.py`, not by a separate model control file.

## Inputs

- Stage 1 forcing JSON, normally `work/forcing.json`.
- Stage 2 parameter JSON for simulation mode, normally `work/params.json`.
- Basin area in `km2`; `tools/run_kineros2.py` uses it for the `mm/d` to `m3/s` conversion.
- Basin latitude in degrees for internal Hamon PET.
- For calibration, an observed discharge CSV or TSV accepted by `tools/run_kineros2.py::load_observed`.

## Outputs

- A complete simulate or calibrate command line for stage 5 or stage 7.
- A consistent set of area, latitude, calibration-window, and spinup assumptions.

## Procedure

1. Read the model's declared bounds, outputs, and caveats:

   ```bash
   sed -n '1,220p' dag.yaml
   sed -n '1,220p' docs/format_spec.yaml
   python tools/run_kineros2.py --help
   ```

2. Configure a simulation command with area in `km2` and latitude in degrees:

   ```bash
   python tools/run_kineros2.py \
     --mode simulate \
     --forcing work/forcing.json \
     --params work/params.json \
     --basin-area-km2 121330 \
     --latitude 33 \
     --output work/simulation.json
   ```

3. Configure calibration so the spinup year is excluded from the objective. The KI validation notes use 1980 as spinup and 1981-1985 for calibration:

   ```bash
   python tools/run_kineros2.py \
     --mode calibrate \
     --forcing work/forcing.json \
     --observed /path/to/observed_Q.csv \
     --basin-area-km2 121330 \
     --latitude 33 \
     --cal-start 1981-01-01 \
     --cal-end 1985-12-31 \
     --maxiter 150 \
     --popsize 20 \
     --output work/calibrated.json
   ```

## Verification

Run:

```bash
python preflight_check.py
```

The preflight smoke simulation exercises `tools/run_kineros2.py --mode simulate` with a tiny generated forcing and parameter file. For real runs, verify that the selected forcing period overlaps any observed discharge period and that the calibration start date is after the spinup year.

## Traps

- `dt_kineros2_006`: Basin area supplied in hectares instead of `km2` makes discharge conversion wrong by a factor of 100.
- `dt_kineros2_011`: Including the spinup year in calibration or using a non-overlapping observed record drives bad objective values.
- `dt_kineros2_013`: The KI applies a lumped daily approximation to large basins; peak timing limits are structural for areas such as the 121,330 `km2` Huai/Bengbu basin.
- `dt_kineros2_015`: `alpha` should remain in `[1.0, 2.0]`; values outside that range indicate overfitting or a prior unit/configuration error.
- `dt_kineros2_022`: Calibration requires SciPy because the runner imports `scipy.optimize.differential_evolution`.

## Example

Configuration for a single forward Bengbu-style simulation:

```bash
python tools/run_kineros2.py \
  --mode simulate \
  --forcing work/forcing_1980_1990.json \
  --params work/params_silt_loam.json \
  --basin-area-km2 121330 \
  --latitude 33 \
  --output work/simulation_bengbu.json
```
