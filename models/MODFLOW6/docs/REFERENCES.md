# MODFLOW 6 — Documentation References

## Official Documentation
- [MODFLOW 6 Homepage](https://water.usgs.gov/ogw/modflow/) — model overview and downloads
- [MODFLOW 6 User Guide](https://water.usgs.gov/water-resources/software/MODFLOW-6/mf6io_6.4.2.pdf) — comprehensive guide to model setup and operation
- [MODFLOW 6 Technical Reference](https://pubs.usgs.gov/tm/06/a55/) — equations, algorithms, numerical methods (USGS Techniques and Methods 6-A55)
- [MODFLOW 6 Input/Output Reference](https://water.usgs.gov/water-resources/software/MODFLOW-6/) — file formats, variable names, units
