## Key Papers

### Core Method
- Berger, M.J., George, D.L., LeVeque, R.J., Mandli, K.T. (2011).
  "The GeoClaw software for depth-averaged flows with adaptive refinement."
  *Advances in Water Resources*, 34(9), 1195-1206.
  DOI: 10.1016/j.advwatres.2011.02.016

### Clawpack Framework
- Clawpack Development Team (2020).
  "Clawpack Version 5.7.1."
  DOI: 10.5281/zenodo.4025432

- LeVeque, R.J., Mandli, K.T., et al. (2016).
  "Clawpack: building an open source ecosystem for solving hyperbolic PDEs."
  *PeerJ Computer Science*, 2:e68.
  DOI: 10.7717/peerj-cs.68

### Tsunami Modeling
- George, D.L., LeVeque, R.J. (2006).
  "Finite volume methods and adaptive refinement for global tsunami propagation and local inundation."
  *Science of Tsunami Hazards*, 24(5), 319-328.

- Gonzalez, F.I., LeVeque, R.J., Chamberlain, P., et al. (2011).
  "Validation of the GeoClaw model."
  NOAA PMEL Technical Report.

### Storm Surge
- Mandli, K.T., Dawson, C.N. (2014).
  "Adaptive mesh refinement for storm surge."
  *Ocean Modelling*, 75, 36-50.
  DOI: 10.1016/j.ocemod.2014.01.002

### Boussinesq Extension
- Kim, J., LeVeque, R.J., George, D.L. (2023).
  "Dispersive wave modeling with GeoClaw using Boussinesq corrections."
