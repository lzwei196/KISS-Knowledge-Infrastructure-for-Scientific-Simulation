# QUINCY atmospheric CO2 record

`tools/build_quincy_climate.py` reads `co2_1901_2014.txt` and `co2_annmean_mlo.txt`
from `CO2_DIR` (on the server: `<models>/QUINCY/inputs/co2/`, outside the KI). The files
are here so a desktop setup can place them; pointing `CO2_DIR` at them is a setup step.

`inputs/co2/README.md` gives the sources (Law Dome ice core, NOAA Mauna Loa) and
`inputs/co2/SHA256SUMS` the hashes. Copied from the server on 2026-11-11.
