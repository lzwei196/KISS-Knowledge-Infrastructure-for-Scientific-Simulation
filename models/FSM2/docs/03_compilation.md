# Stage 3: Compilation

## Purpose

Build the FSM2 Fortran executable from source, selecting physics options at
compile time via C preprocessor defines. Each combination of options produces
a distinct model binary.

## Inputs

| Item | Description |
|------|-------------|
| `src/*.F90` | 22 Fortran source files |
| `compil.sh` | Build script (ASCII output) |
| `compil_nc.sh` | Build script (NetCDF output) |
| gfortran | GCC Fortran compiler |
| libnetcdff | NetCDF-Fortran library (optional) |

## Outputs

- `FSM2` executable in repository root
- `src/OPTS.h` preprocessor header (generated by build script)

## Procedure

1. **Select physics options** by editing the `#define` statements in `compil.sh`:

   | Option | Values | Recommended |
   |--------|--------|-------------|
   | ALBEDO | 1 (diagnostic), 2 (prognostic) | 2 |
   | CANMOD | 1 (single layer), 2 (two layers) | 1 |
   | CONDCT | 0 (fixed), 1 (density-dependent) | 1 |
   | DENSTY | 0 (fixed), 1 (age), 2 (overburden) | 1 or 2 |
   | EXCHNG | 0 (neutral), 1 (stability-corrected) | 1 |
   | HYDROL | 0 (free-drain), 1 (bucket), 2 (gravitational) | 1 |

2. **Run the build script**:
   ```bash
   bash compil.sh      # ASCII output
   # or
   bash compil_nc.sh   # NetCDF output (requires libnetcdff)
   ```

3. **Verify** the binary was created:
   ```bash
   ls -la FSM2
   file FSM2    # should show "ELF 64-bit ... executable"
   ```

## Compilation Order (critical)

The source files must be compiled in dependency order. `FSM2_MODULES.F90` defines
all module data and must come first, followed by `FSM2_PARAMS.F90`:

```
FSM2_MODULES.F90 → FSM2_PARAMS.F90 → FSM2.F90 → FSM2_DRIVE.F90 →
FSM2_OUTPUT.F90 → FSM2_VEG.F90 → FSM2_TIMESTEP.F90 → CANOPY.F90 →
INTERCEPT.F90 → LUDCMP.F90 → PSIMH.F90 → QSAT.F90 → SNOW.F90 →
SOIL.F90 → SOLARPOS.F90 → SRFEBAL.F90 → SWRAD.F90 → THERMAL.F90 →
TRIDIAG.F90 → TWOSTREAM.F90
```

For NetCDF builds, also include `FSM2_PREPNC.F90` and `FSM2_WRITENC.F90`.

## Verification

- Binary exists and is executable
- Run quick smoke test: `./FSM2 < nlst_Alptal.txt` should produce output files
- Check that OPTS.h contains expected option values

## Traps

| Trap | Symptom | Fix |
|------|---------|-----|
| gfortran not installed | `command not found` | `apt install gfortran` |
| Wrong compilation order | "undefined reference" link errors | Use order from compil.sh |
| NetCDF headers missing | `fatal error: netcdf.h: No such file` | `apt install libnetcdff-dev` |
| OPTS.h not generated | Random default options used | Ensure `cat > OPTS.h` runs first |
| Stale .mod files | Type mismatch errors on recompile | Delete `src/*.mod` before rebuild |
| PROFNC=1 with Npnts>1 | Runtime error: "NetCDF output only available for Npnts = 1" | Use PROFNC=0 for multi-point |
| Missing `-cpp` flag | Preprocessor defines ignored | Ensure `-cpp` is in compile command |

## Example

```python
from ki.tools.run_fsm2 import compile_fsm2

binary = compile_fsm2(
    source_dir="/path/to/FSM2/source/repo",
    options={"ALBEDO": 2, "DENSTY": 2, "HYDROL": 1, "CONDCT": 1,
             "EXCHNG": 1, "CANMOD": 1, "PROFNC": 0},
)
print(f"Binary at: {binary}")
```
