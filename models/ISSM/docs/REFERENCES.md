# ISSM References

## Official Resources

- **Source Code**: https://github.com/ISSMteam/ISSM
- **Documentation**: https://issmteam.github.io/ISSM-Documentation/
- **License**: BSD 3-Clause

## Key Publications

- Larour, E., Seroussi, H., Morlighem, M., & Rignot, E. (2012). Continental scale, high order, high spatial resolution, ice sheet modeling using the Ice Sheet System Model (ISSM). *Journal of Geophysical Research: Earth Surface*, 117(F1). doi:10.1029/2011JF002140

- Seroussi, H., Morlighem, M., Larour, E., Rignot, E., & Khazendar, A. (2014). Hydrostatic grounding line parameterization in ice sheet models. *The Cryosphere*, 8, 2075-2087. doi:10.5194/tc-8-2075-2014

- Schlegel, N.-J., et al. (2018). Exploration of Antarctic ice sheet 100-year contribution to sea level rise and associated model uncertainties using the ISSM framework. *The Cryosphere*, 12, 3511-3534.

## External Data Sources

- **BedMachine**: https://nsidc.org/data/idbmg4 — Antarctic/Greenland bed topography
- **MEaSUREs Velocity**: https://nsidc.org/data/measures — Ice velocity observations
- **SeaRISE**: Standard dataset for ice sheet model intercomparison
- **RACMO2 SMB**: Utrecht University — Regional atmospheric climate model output

## Related Solver Libraries

- **PETSc**: https://petsc.org — Portable Extensible Toolkit for Scientific Computation
- **Triangle**: https://www.cs.cmu.edu/~quake/triangle.html — Mesh generation
- **M1QN3**: INRIA — Large-scale optimization (used for inverse methods)
- **Dakota**: https://dakota.sandia.gov — Uncertainty quantification framework
