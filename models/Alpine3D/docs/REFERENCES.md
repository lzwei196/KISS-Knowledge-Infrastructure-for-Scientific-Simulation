## Related Models and Tools

- **SNOWPACK**: 1D multi-layer snow cover model (standalone component)
- **MeteoIO**: Meteorological data I/O and preprocessing library
- **PREVAH**: Hydrological model often coupled with Alpine3D for streamflow
