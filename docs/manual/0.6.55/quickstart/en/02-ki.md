# 2 Set up the KI and model

**Goal:** make the genuine SHAW 3.03 program usable. A KI is the model's instructions and tools; it is not the installed scientific program.

## Install or check the software

1. Open **KI Library**, search `SHAW` and select it. Choose **DeepSeek (API)** and click **Set up with agent**.
2. On **Agent setup**, keep **Install or build a new copy**. Use a short writable folder, for example `D:\GeoForge\models\SHAW`, and click **Use this location** if you change it.
3. Select `deepseek-chat` and click **Start agent setup**. Keep the app open. Downloads and compilation may take several minutes; read any **Needs you** request.
4. Wait for GeoForge's final verification. If it fails, read **Verification** and use **Continue repair**. Do not treat an agent's “installed” message or a printed version banner as proof.

Already have SHAW? Select **Use software already installed**, paste its executable path, choose **Use path**, then **Verify existing software**. Keep its required runtime DLLs with the executable.

For a GNU Fortran build, ask the setup agent to check `libgfortran-5.dll`, `libgcc_s_seh-1.dll`, `libwinpthread-1.dll` and `libquadmath-0.dll` from the same compiler, plus `matplotlib` in the KI's Python environment. The current KI instructions and preflight cover these dependencies.

> **What passed means:** the software can start and its required environment is available. It does not yet prove that a scientific case ran correctly. Page 3 runs and checks the actual model.

## Obtain the authentic Trial inputs

Download the USDA-ARS [official Shaw303.zip](https://www.ars.usda.gov/ARSUserFiles/20520500/SHAW/303/Shaw303.zip). Open its **`Shaw303/` folder** and extract these five files (not the precomputed files in `Output/Trial/`):

| File | Purpose |
|---|---|
| `Trial.303.inp` | Original control and output choices |
| `Trial.30.sit` | Site and soil parameters |
| `Trial.30.wea` | Weather forcing |
| `Trial.moi` | Initial moisture |
| `Trial.tem` | Initial temperature |

Return to your SHAW chat. Use **＋ Files** to attach the five files. If the review asks for an input, use that row's **Upload files** so the file is bound to the plan. Preserve the filenames, contents and control flags.

**Checkpoint:** software verification passed; all five original inputs are available. Setup may require assistance: the verified Windows installation needed a compiler runtime repair. Never replace the model with invented calculations or example output.
