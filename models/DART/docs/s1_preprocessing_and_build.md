# Stage 1: Preprocessing and Build

## Purpose

Compile DART executables from Fortran source and generate model-specific
observation type modules via the `preprocess` program. This stage must
complete before any other DART stage can run.

## Inputs

| File | Format | Description |
|---|---|---|
| `mkmf.template` | Text | Compiler flags, NetCDF paths |
| `path_names_*` | Text | Source file lists per executable |
| `DEFAULT_obs_def_mod.F90` | Fortran | Template for observation definitions |
| `DEFAULT_obs_kind_mod.F90` | Fortran | Template for observation quantities |
| `obs_def_*.f90` files | Fortran | Forward operator definitions |
| `*_quantities_mod.f90` files | Fortran | Physical quantity definitions |

## Outputs

| File | Format | Description |
|---|---|---|
| `obs_def_mod.f90` | Fortran | Generated observation type module |
| `obs_kind_mod.f90` | Fortran | Generated observation quantity module |
| `preprocess` | Binary | Preprocess executable |
| `filter` | Binary | Main assimilation executable |
| `perfect_model_obs` | Binary | Synthetic obs generator |
| `create_obs_sequence` | Binary | Obs template creator |
| `create_fixed_network_seq` | Binary | Obs replication tool |
| `obs_diag` | Binary | Diagnostics executable |

## Procedure

### Step 1: Configure Compiler Template

```bash
cd DART/build_templates
cp mkmf.template.gfortran mkmf.template
```

Edit `mkmf.template` to set:
- `NETCDF` path (e.g., `/usr` or `/usr/local`)
- Compiler flags (`FFLAGS`)
- Linker flags (`LDFLAGS`)
- Include paths (`INCS = -I$(NETCDF)/include`)
- Library paths (`LIBS = -L$(NETCDF)/lib -lnetcdff -lnetcdf`)

### Step 2: Build Model

```bash
cd DART/models/lorenz_63/work
./quickbuild.sh nompi    # serial build
# OR
./quickbuild.sh          # MPI build
```

The `quickbuild.sh` script:
1. Sets the DART root directory
2. Sources `buildfunctions.sh` for shared build logic
3. Runs `preprocess` to generate `obs_def_mod.f90` and `obs_kind_mod.f90`
4. Iterates over all programs in `path_names_*`, running `mkmf` + `make`

### Step 3: Verify Build

```bash
ls -la filter perfect_model_obs preprocess create_obs_sequence
```

All executables should exist and be non-zero size.

## Verification

- All executables listed in `quickbuild.sh` exist in `work/`
- `obs_def_mod.f90` and `obs_kind_mod.f90` were generated by preprocess
- `./filter --help` or a quick dry run produces no link errors
- `ncdump --version` confirms NetCDF library is accessible

## Traps

1. **NetCDF compiled with different compiler**: If NetCDF was built with
   gcc but DART is compiled with ifort, linking will fail. Rebuild NetCDF
   with the same compiler, or use a compatible distribution.

2. **Missing NetCDF Fortran interface**: The `-lnetcdff` (note double-f)
   is the Fortran interface. Without it, you get undefined reference
   errors for `nf90_*` functions.

3. **Record marker mismatch**: gfortran defaults to 4-byte record markers.
   If reading files created by ifort (8-byte default), set
   `-frecord-marker=4` or `-frecord-marker=8` in FFLAGS.

4. **MPI compiler mismatch**: The `mpif90` wrapper must use the same
   underlying compiler (gfortran, ifort, etc.) as specified in `mkmf.template`.

## Example

```bash
# Full build for Lorenz 96 with gfortran
export NETCDF=/usr
cd DART/build_templates
cp mkmf.template.gfortran mkmf.template
cd ../models/lorenz_96/work
./quickbuild.sh nompi

# Verify
ls -la filter perfect_model_obs preprocess
./perfect_model_obs  # Quick test — should produce obs_seq.out
```
