# Stage 3: Configuration (setrun.py)

## Purpose

Create the master configuration file (`setrun.py`) that defines all simulation
parameters: domain extent, grid resolution, time stepping, numerical method,
physics options, AMR settings, topography files, output specification, and
gauge locations.  This is the most complex stage because it coordinates all
other stages and a single wrong parameter can produce silent failures.

## Prerequisites

- Stage 1 (bathymetry) completed — topo files available
- Stage 2 (earthquake source) completed — dtopo files available (if tsunami)
- Domain bounds and resolution determined
- Output times and gauge locations defined

## Inputs

| Input | Format | Units | Notes |
|-------|--------|-------|-------|
| Domain bounds | 4 floats | meters or degrees | Must match topo coordinate system |
| Grid resolution | 2 integers (mx, my) | cells | Coarsest AMR level |
| Simulation time | 2 floats (t0, tfinal) | **seconds** | Not minutes or hours |
| AMR levels | integer | — | 1 = no refinement |
| Refinement ratios | integer array | — | Length = amr_levels_max − 1 |
| Topography files | file paths | — | From Stage 1 |
| dtopo files | file paths | — | From Stage 2 (optional) |
| Gauge locations | (id, x, y, t1, t2) | — | Coordinates match domain |

## Outputs

| Output | Format | Description |
|--------|--------|-------------|
| `setrun.py` | Python script | Complete GeoClaw configuration |
| `*.data` files | Fortran data | Generated by `python setrun.py` |

## Procedure

1. **Choose coordinate system.**
   - `coordinate_system=1` for Cartesian (meters) — lab-scale or local problems
   - `coordinate_system=2` for lat-lon (degrees) — real-world ocean/coastal problems

2. **Set domain bounds.**  Must fully contain the region of interest.
   For tsunami simulations, include both the source region and the target coast.
   ```python
   clawdata.lower[0] = -80.0   # xlower (west longitude)
   clawdata.upper[0] = -60.0   # xupper (east longitude)
   clawdata.lower[1] = -45.0   # ylower (south latitude)
   clawdata.upper[1] = -15.0   # yupper (north latitude)
   ```

3. **Set grid resolution.**  The coarsest level should resolve the dominant
   wavelength.  For tsunamis in deep ocean, typical cell size is 0.1–0.5°.
   AMR handles nearshore refinement.
   ```python
   clawdata.num_cells[0] = 200  # ~0.1° per cell
   clawdata.num_cells[1] = 300
   ```

4. **Set time parameters.**  All times in SECONDS.
   ```python
   clawdata.t0 = 0.0
   clawdata.tfinal = 3600.0 * 6  # 6 hours = 21600 seconds
   ```

5. **Configure AMR.**  Use 2–4 levels for real applications.
   ```python
   amrdata.amr_levels_max = 3
   amrdata.refinement_ratios_x = [4, 6]  # Level 1→2: 4×, Level 2→3: 6×
   amrdata.refinement_ratios_y = [4, 6]
   amrdata.refinement_ratios_t = [4, 6]
   ```

6. **Set physics parameters.**
   ```python
   geo_data.gravity = 9.81
   geo_data.coordinate_system = 2
   geo_data.sea_level = 0.0
   geo_data.friction_forcing = True
   geo_data.manning_coefficient = 0.025
   geo_data.dry_tolerance = 1e-3
   ```

7. **Register topography and dtopo files.**
   ```python
   topo_data.topofiles.append([2, 'ocean_bathy.tt2'])
   topo_data.topofiles.append([3, 'coast_dem.asc'])
   dtopo_data.dtopofiles.append([3, 'earthquake.tt3'])
   ```

8. **Add gauges** at tide gauge locations or points of interest.
   ```python
   gaugedata.gauges.append([1, -73.0, -36.7, 0.0, 21600.0])
   ```

9. **Generate data files:**
   ```bash
   python setrun.py   # creates claw.data, geoclaw.data, topo.data, etc.
   ```

## Verification

- [ ] `coordinate_system` matches topo file coordinates
- [ ] Domain bounds are in correct units (degrees for lat-lon, meters for Cartesian)
- [ ] `tfinal` is in seconds (not minutes or hours) — see dt_003
- [ ] `cfl_desired` < 1.0 — see dt_011
- [ ] `refinement_ratios` array has length `amr_levels_max - 1` — see dt_013
- [ ] All topo files listed in `topo_data.topofiles` exist
- [ ] All dtopo files listed in `dtopo_data.dtopofiles` exist
- [ ] Gauge coordinates are within the computational domain
- [ ] `python setrun.py` runs without errors and generates .data files

## Traps

| Trap | Triplet | Impact |
|------|---------|--------|
| Time in minutes/hours instead of seconds | dt_003 | Simulation too short or too long |
| CFL ≥ 1.0 | dt_011 | Numerical instability, NaN |
| AMR ratio array wrong length | dt_013 | Fortran runtime error |
| Gauge outside domain | dt_016 | Missing gauge output, no error |
| Coordinate mismatch | dt_002 | Domain doesn't match topo |
| Missing topo files | dt_014 | Zero bathymetry in missing regions |

## Example

Using `generate_setrun.py` to create a configuration from JSON:

```bash
cat > config.json << 'EOF'
{
  "domain": {
    "xlower": -80.0, "xupper": -60.0,
    "ylower": -45.0, "yupper": -15.0,
    "mx": 200, "my": 300,
    "bc_lower": ["extrap", "extrap"],
    "bc_upper": ["extrap", "extrap"]
  },
  "time": {"t0": 0.0, "tfinal": 21600.0},
  "output": {"output_style": 1, "num_output_times": 24, "output_format": "ascii"},
  "physics": {
    "coordinate_system": 2, "gravity": 9.81,
    "sea_level": 0.0, "friction_forcing": true,
    "manning_coefficient": 0.025, "dry_tolerance": 0.001
  },
  "amr": {
    "amr_levels_max": 3,
    "refinement_ratios_x": [4, 6],
    "refinement_ratios_y": [4, 6],
    "refinement_ratios_t": [4, 6],
    "wave_tolerance": 0.01
  },
  "topography": {"files": [{"type": 2, "path": "ocean_bathy.tt2"}]},
  "dtopo": {"files": [{"type": 3, "path": "earthquake.tt3"}]},
  "gauges": [{"id": 1, "x": -73.0, "y": -36.7, "t1": 0, "t2": 21600}]
}
EOF

python ki/tools/generate_setrun.py --config config.json --output setrun.py
```
