# Stage 3 — Report and obtain selection

For each plausible returned record, show its exact dataset ID, name, variable,
coverage, temporal range, resolution, delivery tier, and size when present.
Clearly separate server-delivered records from manual Baidu Pan delivery.

Do not say a dataset was downloaded merely because it exists in the catalogue.
Do not present a reference result, placeholder, or generated array as retrieved
data. Ask the user to confirm the chosen record before the Desktop flow adds it
to the approved inventory and performs a download.
