# Bounded native startup

The earlier native build succeeded but interactive PHREEQC startup hung on stdin. GeoForge now caps installation-only native help/version probes at25seconds and closes stdin. Use the official console binary and its distributed phreeqc.dat database. Do not create a scientific case merely to prove startup; inspect the resulting version/banner or missing-input diagnostic. Do not repeat an identical timed-out command indefinitely. Preserve the exact expected native product path in the installation manifest.
