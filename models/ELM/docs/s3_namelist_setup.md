# Stage 3: Namelist Configuration

## Purpose

Generate and customize the ELM runtime namelist (lnd_in) that controls all
model physics options, input file paths, output configuration, and simulation
parameters. The namelist is a Fortran namelist file generated by CIME's
build-namelist utility and customized through user_nl_elm.

## Prerequisites

- Stage 0 completed (E3SM installed)
- Stage 1 completed (surface dataset available)
- A CIME case created (via create_newcase)

## Inputs

| Input | Source | Description |
|-------|--------|-------------|
| Compset definition | config_compsets.xml | Determines default BGC mode |
| user_nl_elm | Case directory | User customizations |
| namelist_defaults.xml | bld/namelist_files/ | Default values for all parameters |
| config_component.xml | cime_config/ | Component-level defaults |

## Outputs

| Output | Location | Description |
|--------|----------|-------------|
| lnd_in | Case run directory | Complete Fortran namelist for ELM |
| drv_flds_in | Case run directory | Driver field exchange configuration |

## Procedure

### 1. Understand the namelist hierarchy

ELM namelists are assembled from multiple sources in this priority order
(highest priority first):

1. **user_nl_elm** — User overrides (you edit this)
2. **Compset defaults** — Set by the chosen compset
3. **namelist_defaults.xml** — Factory defaults for all parameters
4. **Hardcoded defaults** — In source code

### 2. Edit user_nl_elm

**CRITICAL (dt_008)**: Fortran namelists require **single quotes** for string
values. Double quotes will cause a parse failure and the model will not start.

```fortran
! CORRECT — single quotes
fsurdat = '/path/to/surfdata.nc'
hist_fincl1 = 'GPP','NPP','QRUNOFF'

! WRONG — double quotes (dt_008: FATAL)
fsurdat = "/path/to/surfdata.nc"
```

### 3. Common configuration patterns

#### Satellite phenology (SP) — fastest testing mode

```fortran
! In user_nl_elm:
! (Most settings come from the IELM compset)
hist_nhtfrq = 0         ! Monthly output
hist_mfilt = 12          ! 12 months per file
```

#### Full biogeochemistry (BGC)

```fortran
! Use compset I1850CNPRDCTCBCTOP, then add:
co2_ppmv = 284.7         ! 1850 CO2 level
suplnitro = 'NONE'       ! N limitation active
suplphos = 'NONE'        ! P limitation active
hist_fincl1 = 'GPP','NPP','NEE','HR','TOTECOSYSC','TOTSOMC','TOTVEGC'
```

#### Spin-up configuration (dt_009)

```fortran
! Accelerated decomposition spin-up (first 200+ years)
spinup_state = 1
! Normal mode after spin-up converges
spinup_state = 0
```

#### Custom forcing data

```fortran
! Point to custom DATM forcing files
! (Usually configured through DATM namelists, not user_nl_elm)
```

### 4. Key namelist parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| dtime | integer | 1800 | Timestep (seconds). **Do not change without care** (dt_005) |
| co2_type | char | 'constant' | CO2 source: constant, diagnostic, prognostic |
| co2_ppmv | real | 284.7 | CO2 concentration (ppmv) for constant mode (dt_012) |
| bgc_mode | char | compset | sp, cn, bgc — controls BGC complexity |
| use_cn | logical | compset | Enable carbon-nitrogen cycling |
| use_crop | logical | .false. | Enable prognostic crop model |
| irrigate | logical | .false. | Enable irrigation |
| nu_com | char | 'RD' | Nutrient competition: RD, ECA, MIC |
| fsurdat | char | auto | Path to surface dataset |
| finidat | char | '' | Initial conditions (empty = cold start) |
| paramfile | char | auto | Path to parameter file |
| hist_nhtfrq | int(6) | 0 | Output frequency (0=monthly, -N=N-hourly) |
| hist_mfilt | int(6) | 12 | Max time samples per output file |
| hist_fincl1-6 | char(1500) | varies | Variables to include |
| hist_fexcl1-6 | char(1500) | '' | Variables to exclude |

### 5. Generate the final namelist

```bash
cd /path/to/case
./preview_namelists    # Preview without committing
./case.build           # Also generates namelists
cat run/lnd_in         # Inspect the final namelist
```

## Verification

- [ ] All file paths in lnd_in exist and are readable
- [ ] String values use single quotes, not double quotes (dt_008)
- [ ] co2_ppmv matches the intended scenario period (dt_012)
- [ ] dtime matches the expected coupling interval (dt_005)
- [ ] History output variables are correctly specified
- [ ] fsurdat resolution matches the case resolution

## Traps

| Trap | dt_ID | Symptom | Prevention |
|------|-------|---------|------------|
| Double quotes | dt_008 | Fatal: "No valid entries in namelist" | Always use 'single quotes' |
| Wrong timestep | dt_005 | Numerical instability, CFL violation | Keep dtime=1800 unless you know why |
| Wrong CO2 | dt_012 | GPP magnitude off by 30-50% | Match co2_ppmv to simulation year |
| No spin-up | dt_009 | Zero carbon pools, unrealistic NEE | Run 200-500 yr spin-up first |
| Wrong finidat | dt_018 | Grid mismatch → interpolation artifacts | Ensure finidat matches resolution |

## Example

```bash
# Create case with full BGC
cd E3SM/cime/scripts
./create_newcase --case ../../bgc_test \
    --compset I1850CNPRDCTCBCTOP \
    --res ne4pg2_ne4pg2 \
    --mach chrysalis

cd ../../bgc_test
./case.setup

# Customize namelist
cat >> user_nl_elm << 'EOF'
hist_nhtfrq = 0, -24
hist_mfilt = 12, 365
hist_fincl1 = 'GPP','NPP','NEE','HR','FSH','EFLX_LH_TOT','QRUNOFF'
hist_fincl2 = 'GPP','FSH','QRUNOFF','H2OSOI','TSOI'
co2_ppmv = 284.7
EOF

# Preview and verify
./preview_namelists
grep -E "fsurdat|co2_ppmv|hist_" run/lnd_in
```
