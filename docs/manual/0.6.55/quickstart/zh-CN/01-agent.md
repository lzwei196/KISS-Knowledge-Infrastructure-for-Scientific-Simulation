# 1 配置 Agent

**目标：** 先连接 AI，再开始科学项目。本 Windows 指南使用 DeepSeek API；第 3 页的真实示例也由这个接口完成。

## 连接 DeepSeek

1. 打开 GeoForge Desktop，点击 **设置 → AI 服务**。
2. 在 **DeepSeek (API)** 卡片上点击 **获取密钥**，在你自己的服务商账户里创建 API 密钥。返回 GeoForge，把密钥粘贴到卡片的密钥输入框。
3. 选中 **默认使用**，点击 **保存**，再点击 **测试 AI 与 GitHub**。保存成功不等于连接成功。
4. AI 测试通过后关闭设置。侧栏应显示 **AI 就绪**。若失败，先读测试错误，再检查服务商账户及 **网络与代理** 设置。

> **保护凭据。** API 密钥只填在设置中。不要把 API 密钥或 GeoForge 数据库 Token 发到聊天、截图或项目文件里。本例不需要 GeoForge 数据库。

## 新建项目

1. 点击 **＋ 新建对话**，命名为 `SHAW official Trial`。选择项目父文件夹，例如 `D:\GeoForge\projects`。Windows 浏览器模式下直接粘贴路径。
2. 在第一条消息发出前，在对话顶部选择 **API → DeepSeek (API) → deepseek-chat**。
3. 点击 **自动选择 KI**，搜索 `SHAW`，选中后点击 **应用**，然后继续第 2 页。

项目文件夹保存这个对话的输入、结果和运行记录。模型软件有独立的安装文件夹，可以被后续项目复用。

## 也可以使用本地 CLI

按 Claude Code 或 OpenAI Codex 等 CLI 自己的说明完成安装和登录。在 **设置 → AI 服务** 中点击 **重新检查本地 CLI**；在第一条消息前选择 **本地** 和对应 Agent。这是另一种连接方式；本指南的完整示例使用 DeepSeek API 验证。

**检查点：** AI 测试通过；新对话显示正确的 AI 和 SHAW。第一条消息发出后，要更换 AI 或 KI，请新建对话。
