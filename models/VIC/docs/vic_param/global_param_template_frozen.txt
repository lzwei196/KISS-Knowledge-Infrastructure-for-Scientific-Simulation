# VIC 5.1.0 classic-driver global parameter TEMPLATE (KI-shipped).
#
# Every line that config_paths.create_global_param() rewrites is anchored at
# column 0: FORCING1, SOIL, VEGLIB, VEGPARAM, RESULT_DIR, OUTFILE, STARTYEAR,
# ENDYEAR, FORCEYEAR.  Everything else is a validated default that reproduced
# the Bengbu 51080 and 唐乃亥 routed-discharge runs.
#
# Do NOT hand-edit per basin.  Set the VIC_* environment variables documented in
# SKILL.md and run  `python -c "import config_paths; config_paths.create_global_param()"`.
#
# COLD-REGION variant: FULL_ENERGY FALSE (water balance) + FROZEN_SOIL TRUE.
# Use this template for snow/frost-dominated basins (哈尔滨 Songhua, and any basin
# with a deep seasonal frost layer).  See dt_vic_031.
#
# VIC auto-sets QUICK_FLUX=FALSE when FROZEN_SOIL is TRUE
# (drivers/classic/src/get_global_param.c:111), which in turn leaves EXP_TRANS at its
# TRUE default.  EXP_TRANS then requires  5*ln(dp+1) < NODES-1  (read_soilparam.c:770).
# The KI's soil files carry dp = 4.0 m (fill_parameters1.py col 27), so 5*ln(5) = 8.05
# and NODES must be >= 10.  NODES 3 (the water-balance default) and NODES 7 both abort
# with 'The number of soil thermal nodes is too small for the supplied damping depth'.
# See dt_vic_031.
#
# REQUIRES a soil parameter file with real `bubble` (cols 28-30) and
# `fs_active`=1 (col 53).  fill_parameters2.py writes both since dt_vic_031;
# older SOIL_PARAM_COMPLETE.txt files carry bubble=-9999 / fs_active=0 and will
# make VIC's estimate_layer_ice_content() operate on sentinel values.  The 21 OUTVARs below are REQUIRED in
# this exact order: s5_routing / SKILL.md slice the flux file as
#     df.iloc[:, [0, 1, 2, 3, 18, 16, 17]]
#       -> year month day OUT_PREC OUT_EVAP OUT_RUNOFF OUT_BASEFLOW
# which is the 7-column input Lohmann `rout` expects.  Reordering or removing an
# OUTVAR silently feeds `rout` the wrong columns.
