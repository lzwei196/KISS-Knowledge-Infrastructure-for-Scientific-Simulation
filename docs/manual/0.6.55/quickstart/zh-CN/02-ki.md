# 2 配置 KI 与模型软件

**目标：** 让真正的 SHAW 3.03 程序能在本机运行。KI 是模型的知识、说明和工具，不等于已经安装好的科学模型程序。

## 安装或验证软件

1. 打开 **KI 库**，搜索并选择 `SHAW`。选择 **DeepSeek (API)**，点击 **使用 Agent 设置**。
2. 在 **Agent 设置** 中保留 **安装或编译新的副本**。建议用简短、可写的路径，例如 `D:\GeoForge\models\SHAW`；修改后点击 **使用此位置**。
3. 选择 `deepseek-chat`，点击 **开始 Agent 设置**。保持应用运行；下载和编译可能需要几分钟，留意 **需要你** 中的要求。
4. 等 GeoForge 的最终验证。失败时先读 **验证**，再用 **继续修复**。Agent 说“安装好了”，或程序只打印了版本号，都不能证明安装通过。

已有 SHAW？选择 **使用已经安装的软件**，粘贴可执行文件路径，点击 **使用此路径**，再点击 **验证已有软件**。保留可执行文件所需的运行库 DLL。

若使用 GNU Fortran 编译，请让设置 Agent 核对同一编译器自带的 `libgfortran-5.dll`、`libgcc_s_seh-1.dll`、`libwinpthread-1.dll`、`libquadmath-0.dll`，以及 KI Python 环境中的 `matplotlib`。当前 KI 安装说明和预检包含这些依赖。

> **通过代表什么？** 软件能启动，所需环境可用。它还不证明某个科学算例正确运行。第 3 页将执行并核对真正的模型。

## 准备真实的 Trial 输入

下载 USDA-ARS 的 [官方 Shaw303.zip](https://www.ars.usda.gov/ARSUserFiles/20520500/SHAW/303/Shaw303.zip)，打开其中的 **`Shaw303/` 文件夹**，提取这五个文件，不要把 `Output/Trial/` 下的参考输出当作运行输入：

| 文件 | 用途 |
|---|---|
| `Trial.303.inp` | 原始控制选项与输出列表 |
| `Trial.30.sit` | 场地和土壤参数 |
| `Trial.30.wea` | 气象驱动 |
| `Trial.moi` | 初始含水量 |
| `Trial.tem` | 初始温度 |

回到 SHAW 对话，用 **＋ 文件** 附上这五个文件。若审阅卡片要求提供某项输入，请用该输入行的 **上传文件**，把文件与计划关联。保留原文件名、内容和控制选项。

**检查点：** 软件验证通过，五个原始输入已准备好。安装可能需要协助：本次 Windows 验证曾修复缺失的编译器运行库。不能用自编公式、虚构驱动或现成输出替代模型运行。
