# 3 GeoForge 数据库

本章教你把 GeoForge Desktop 连接到 GeoForge 数据库，确认连接正常，浏览数据库里有哪些数据，并跟踪已批准的数据如何从计划进入你的项目文件夹。

## 3.1 GeoForge 数据库是什么

GeoForge 数据库是一个经过整理的在线目录，收录了约 1,100 个用于环境建模的数据集。内容包括水文站和气象站的观测数据、气象驱动数据和再分析数据、格点产品、土壤图、地形数据等输入。

连接数据库后，Agent 在为你的研究制定计划时可以检索它，并把确切的数据集 ID 写进计划。Agent 自己从不下载任何东西：你批准计划后，由 GeoForge 获取已批准的数据（文件很大时会给你一个下载链接），检查数据，并在项目中记录下来。

数据库是可选的。它和 GeoForge 网页账户无关，需要单独的激活 Token。

| 以下情况需要数据库 | 以下情况可以不用数据库 |
|---|---|
| 你希望 GeoForge 为你的研究区查找并获取观测、驱动或土壤数据 | 你的计划只用 KI 已经知道的公开数据源（例如 NASA POWER） |
| 你希望服务器把大型格点产品裁剪到你的研究区，而不是下载整个文件 | 你使用自己的文件 |
| 你希望每个下载的文件都经过检查，并记录在项目中 | 你运行 KI 自带的示例（FSM2 Alptal 示例不需要数据库） |

## 3.2 获取激活 Token

每个人的 Token 都由 GeoForge 数据库的管理者单独发放。你不能在软件里自己注册。

- Token 是一长串以 `gfd_` 开头的字符。
- 有效期 6 个月。到期后需要重新申请。
- 管理者可以单独吊销某一个人的 Token，不影响其他人。
- 每个 Token 每天的上限是 20 GB 或 2,000 次请求，在服务器时间午夜重置。

> **[待 GeoForge 团队补充]** 如何申请 Token（联系方式、表单、预计需要多久）

> **注意：** 请像对待密码一样对待 Token。不要把它粘贴到对话消息、发给同事的邮件或项目里的文件中。GeoForge 给你看的每个百度网盘链接都会记在你的 Token 名下，所以和别人共用 Token，就要和别人共同承担责任。

## 3.3 在设置中填入 Token

1. 点击左侧边栏底部的 **设置**。
2. 在设置窗口左侧的菜单中，点击 **GeoForge 数据库**。

![保存 Token 之前的 GeoForge 数据库页面](../../images/zh-CN/03-settings-db.png)

检查：顶部的状态标签显示 **未配置**，旁边一行写着“未配置 Token：Agent 无法检索 GeoForge 数据库。”；**数据库里有什么** 下方用红字显示 “Paste your activation token in Settings.”（请在设置中粘贴激活 Token）。这行红字来自数据库服务，以英文显示。这是正常的初始状态。

3. 点击 **激活 Token** 输入框（框里显示“粘贴数据库访问 Token”）。
4. 粘贴你的 Token。字符会显示为圆点。
5. **Agent 数据库访问方式** 保持为 **通过 GeoForge Desktop 直接查询（推荐）**。
6. 点击 **保存并测试数据库**。Token 输入框下方的提示会变成“正在保存并测试数据服务……”。
7. 等待结果。成功时，提示显示“连接成功：目录中有 N 条数据记录。”，其中 N 约为 1,100。
8. 点击 **关闭**。
9. 再次点击 **设置**。
10. 点击 **GeoForge 数据库**。只有重新打开这个页面，状态标签和数据集列表才会刷新。

> **[待补充截图]** 设置 → GeoForge 数据库，已填入有效 Token，**保存并测试数据库** 成功后重新打开：绿色的 **已连接** 状态标签；状态行“本地目录 N 条（M 条可直接下载）· N 分钟前同步”，下面一行“Agent 检索方式：API 使用 search_catalogue 工具，CLI 使用 geoforge-db 命令；两者都读同一份本地目录，Token 留在 Desktop。”；Token 输入框显示圆点；提示“Token 已私密保存在本机，仅你的用户账户可读；Agent 和对话无法读取。”；下方已加载 **数据库里有什么** 列表。

检查：状态标签显示绿色的 **已连接**，状态行显示记录数和最近一次同步时间（“刚刚同步”或“N 分钟前同步”）。

**“保存并测试数据库”做了什么。** 它会保存所有设置页面，而不只是这一页。然后它向数据库发送一次测试请求。测试通过后，GeoForge 会在后台开始下载一份目录的本地副本。这份副本只有描述信息，不含数据文件、链接或密码。

后台下载通常一分钟内完成。如果你在完成前重新打开页面，状态标签可能显示 **未同步**（如果这台电脑以前在没有 Token 的情况下运行过 GeoForge，则可能显示 **不可用**），列表可能显示 “The catalogue is being fetched; try again in a moment.”（正在获取目录，请稍后再试）。等一分钟，关闭设置，再重新打开这个页面。

> **提示：** 窗口底部的 **保存** 也会保存 Token，但不会测试它，也不会下载目录。每次粘贴新的 Token，都请点击 **保存并测试数据库**。

### 更换或删除 Token

保存 Token 后，输入框里只显示圆点。GeoForge 不会再显示已保存的 Token，这些圆点只表示“已经存有 Token”。如果你不动这些圆点，已保存的 Token 会保持不变。

更换 Token：

1. 点击 **激活 Token** 输入框。
2. 全选框里的内容（Windows：Ctrl+A；macOS：Cmd+A）。
3. 按 Delete 键。
4. 粘贴新的 Token。
5. 点击 **保存并测试数据库**。

> **注意：** 粘贴之前先删掉圆点。如果你把新 Token 粘贴在圆点后面，GeoForge 会把整个输入框当作“未更改”，继续使用旧 Token。

删除 Token：

1. 点击 **激活 Token** 输入框。
2. 全选框里的内容（Windows：Ctrl+A；macOS：Cmd+A）。
3. 按 Delete 键，让输入框完全清空。
4. 点击 **保存**。

GeoForge 会删除已保存的 Token。下次打开这个页面时，状态标签显示 **未配置**。

> **提示：** **KI 库** 页面有自己的小设置窗口（⚙），里面也有同样的 Token 输入框。两处保存到同一个地方。本手册使用主窗口的 **设置**。

## 3.4 查看数据库状态

**设置 → GeoForge 数据库** 顶部的状态标签会显示五种状态之一，其中 **已连接** 有两种颜色。

| 状态标签 | 含义 | 怎么做 |
|---|---|---|
| **未配置** | 没有保存 Token，或者 GeoForge 无法从系统密码存储中读取它（见 3.10 节）。 | 填入 Token（见 3.3 节）。 |
| **已关闭** | 你把 **Agent 数据库访问方式** 设成了 **不向 Agent 提供数据库访问**。 | 如果需要数据库，改回 **通过 GeoForge Desktop 直接查询（推荐）**，然后点击 **保存**。 |
| **不可用** | 已保存 Token，但服务器拒绝了它（Token 错误、过期或已被吊销）。第一次保存 Token 后的几秒内也可能显示这个状态。 | 看状态标签旁边那行文字，再参考 3.10 节。 |
| **已连接**（绿色） | Token 有效，本地目录是最新的。 | 不用处理。 |
| **已连接**（黄色） | Token 有效，但上一次刷新失败，通常是因为断网。GeoForge 会继续使用旧的目录副本。 | 检查网络（见 3.10 节）。 |
| **未同步** | Token 有效，但还没有下载目录副本。 | 等一分钟，再重新打开页面。 |

状态标签旁边那行文字会给出详细信息：

- Token 有效时：“本地目录 N 条（M 条可直接下载）· N 分钟前同步”。如果上一次刷新失败，这一行末尾会加上“· 已过期：”和原因。
- 还没有目录副本时：“目录未下载”，有时后面跟着原因。
- Token 被拒绝时：“访问不可用：当前 Token 未获授权，Agent 无法检索 GeoForge 数据库。”，后面跟着服务器的消息。
- 关闭访问时：“已关闭：Agent 不会检索数据库。”

GeoForge 启动时会刷新目录副本，之后每 6 小时刷新一次。

**项目状态 → 更多细节** 里的 **GeoForge 数据库** 卡片也有自己的状态标签，其中两种状态的叫法和设置页不同：

| 项目状态中的标签 | 对应的设置页状态 |
|---|---|
| **未配置** | **未配置** |
| **已关闭** | **已关闭** |
| **不可用** | **不可用** |
| **过期** | **已连接**（黄色） |
| **本地目录** | **已连接**（绿色）或 **未同步** |

### 什么情况下数据库算“已激活”

只有以下三个条件同时满足，GeoForge 才会在项目中使用数据库：

1. **Agent 数据库访问方式** 没有设成 **不向 Agent 提供数据库访问**。
2. 已经保存了 Token。
3. 服务器没有拒绝这个 Token。

断网不会让数据库变成未激活。搜索会继续使用本地目录，并标记为已过期。

数据库未激活时：

- Agent 拿不到数据库工具，并会被告知数据库访问已关闭。
- GeoForge 不会为你的研究推荐数据库里的数据集。
- 如果计划里仍然写了数据库里的数据集，计划会退回给 Agent 修改。
- 批准卡片上不显示 **数据来源，你来选** 列表。
- 只用公开数据源或你自己文件的计划仍然可以正常使用。

如果数据库访问已关闭或 Token 被拒绝，而你批准了一个需要数据库的计划，那么不会批准或下载任何东西。对话中会显示这条英文消息：“GeoForge Database access is off or not activated, but this plan still needs it for … Nothing was approved or downloaded. Activate the Database in Settings and approve again, or choose "Modify the plan" to use public sources or your own files. Your saved choices are retained.” 意思是：数据库未激活，但这个计划需要它；没有批准或下载任何内容；请在设置中激活数据库后重新批准，或者选择 “Modify the plan”（修改计划），改用公开数据源或你自己的文件；你已保存的选择会保留。

## 3.5 浏览目录

在项目开始前或进行中，你都可以自己浏览目录。这样在写请求之前，你就能先看看自己的区域有哪些数据。

### 在设置中浏览

1. 打开 **设置 → GeoForge 数据库**。
2. 向下滚动到 **数据库里有什么**。列表从你电脑上的本地目录读取，所以有了目录副本之后，离线也能用。
3. 要筛选，点击 **按领域**、**按获取方式** 或 **按类型** 下面的筛选按钮。每个按钮上显示它包含的数据集数量。再点一次同一个按钮，就取消筛选。
4. 要搜索，在 **搜索数据集……** 框里输入。输入的文字会和数据集 ID、名称、类型以及变量名进行匹配。
5. 点击某一行，打开它的详情。
6. 点击 **收起**，关闭详情。

> **[待补充截图]** 设置 → GeoForge 数据库，已有有效 Token 时的 **数据库里有什么**：**按领域**、**按获取方式**（**可直接下载**、**网盘手动下载**）和 **按类型** 三行筛选按钮，每个按钮带数量；一行“N 个数据集（共 M）”；各行数据集显示名称、类型、年份、格式、获取方式标签和大小。

检查：列表上方一行写着“N 个数据集（共 M）”。列表最多显示 120 行；超过时，这一行后面会加上“，只显示前 120 个，请用搜索缩小范围”。

**按获取方式** 的筛选按钮告诉你数据集怎样送到你手里：

| 获取方式标签 | 含义 |
|---|---|
| **可直接下载** | GeoForge 可以自己下载文件（单个文件不超过 100 MB）。 |
| **网盘手动下载** | 文件比较大。GeoForge 要么请服务器把它裁剪到你的研究区，要么给你一个百度网盘链接，让你自己下载（见 3.7 节）。 |

详情面板列出 **变量**、**时间**、**范围**、**分辨率**、**格式**、**大小**、**获取方式** 和 **适用领域**。目录里没有值的字段不会显示。

> **[待补充截图]** 设置 → GeoForge 数据库，点击了一行数据集（例如 `cmfd_huai_daily_025` 或 `bengbu_51080`）：列表上方的详情面板，显示数据集名称、它的 ID，以及变量、时间、范围、分辨率、格式、大小、获取方式和适用领域各字段，还有 **收起** 按钮。

检查：面板上显示你点击的数据集名称，名称下方是它的 ID。

浏览时要注意：

- **用英文搜索。** 目录内容是英文的。请用英文名称、站号或数据集 ID 搜索，例如 `huai`、`cmfd` 或 `51080`。中文地名搜不到。
- **这里一次只搜一个词。** 设置页的搜索框按你输入的原样查找，所以 `huai prec` 只能找到包含这个完整短语的记录。
- **大小指整个产品。** 列表里的大小是整个产品的大小，不是你的项目实际要下载的量。3.6 节说明在哪里看实际下载大小。
- **只列出主产品。** 按变量、按年份拆分的子文件被隐藏了，所以这里的总数可能比状态行里的记录数少。

### 在项目中浏览

1. 在已打开的项目对话中，点击右上角的 **◇ 项目状态**。

![项目状态面板，更多细节处于收起状态](../../images/zh-CN/13-project-status-new.png)

检查：**更多细节** 是最后一张卡片，旁边的提示是“下载任务记录、项目文件夹、目录搜索、数据来源、校准”。

2. 点击 **更多细节**，把它展开。
3. 向下滚动到 **更多细节** 里的 **GeoForge 数据库** 卡片。
4. 在搜索框（“变量、地区、时期或数据 ID”）中输入。这里你输入的每个词都必须出现在记录里，所以 `huai prec` 可以搜到。
5. 点击 **搜索**（或按 Enter）。

检查：卡片显示“找到 N 条；显示前 M 条。”，每个数据集一条，带有获取方式标签（**可直接下载** 或 **百度网盘手动下载**）、ID、类型、格式、时段、变量、覆盖范围、适用领域和大小。

6. 想让 Agent 看看某个数据集，点击它下面的 **交给 Agent 检查**。

**交给 Agent 检查** 会关闭 **项目状态**，并向 Agent 发送一条预先写好的消息。消息请 Agent 把这个数据集和 KI 的输入要求做比较，并且在规划阶段只把确切的 ID 写进计划。如果对话还在处理，消息会留在输入框里，等你发送。

如果没有保存 Token，或者 Token 被拒绝，搜索会显示错误信息和一个 **打开 AI 设置** 按钮。这个按钮会打开 **设置** 窗口；在左侧菜单中点击 **GeoForge 数据库**。（这张卡片上的提示仍写着“AI 设置”，指的就是 **设置 → GeoForge 数据库**。）

## 3.6 规划时如何使用数据库

你不必自己去搜目录。数据库激活后，Agent 会在规划时替你搜索。

1. **GeoForge 用你的请求去匹配目录。** GeoForge 把你请求里的词（地名、站号、数据集名称）和本地目录做比较，给 Agent 一份简短的候选清单。站号、流域名和河流名最有用。一些主要的中文地名（例如淮河、蚌埠）在这一步可以识别。
2. **Agent 核对候选数据。** Agent 工作时，输入框上方的活动行可能显示 **正在检索 GeoForge 数据库**。工作详情里会出现 **已检索 GeoForge 数据库**、**已读取数据集字段**（文件里真实的变量名和单位）、**已估算服务器裁剪** 等步骤。Agent 在理解任务阶段可能会请求几次裁剪估算。这些操作只读，不会下载任何东西。
3. **计划里写明确切的 ID。** 计划数据清单中的每项输入都对应一个数据集 ID。你批准之前，不会下载任何东西。
4. **GeoForge 检查计划。** Agent 提交计划后，GeoForge 会在目录里逐个查找这些 ID，并补上获取方式、大小、覆盖范围和时段。目录里找不到的 ID 会退回给 Agent。几百 GB 的整个全国或全球产品，绝不会作为一次下载被接受；计划必须改用服务器裁剪、区域子集，或者按变量、按年份拆分的较小文件。

目录里能匹配到，只说明数据存在，不说明它适合你的模型。Agent 仍要检查单位、分辨率和覆盖范围，你也应该检查。

### 批准卡片上显示什么

批准卡片的标题是 **Approve the plan?**（批准计划？）。这张卡片的标题和选项按钮以英文显示。卡片的 **数据** 部分会把每项输入分组，数据库里的输入出现在其中两组：

| 卡片上的分组 | 行上的标签 | 批准之后会怎样 |
|---|---|---|
| **批准后由 GeoForge 自动下载** | **直接下载** | GeoForge 下载这个文件。 |
| **批准后由 GeoForge 自动下载** | **服务器裁剪后下载** | GeoForge 请服务器按你的研究区、时段和变量裁剪产品，然后下载裁剪结果。 |
| **需要你处理** | **需你从网盘下载（批准后给链接）** | 你自己从百度网盘下载文件（见 3.7 节）。 |

每一行的格式是 `输入 ← 数据集 ID · 大小`。如果 Agent 为某项输入找到了不止一个合适的数据集，卡片上还会显示 **数据来源，你来选**：每个候选数据集一个单选按钮，推荐的那个已经选中。如果你改选另一个再批准，GeoForge 会把计划换成你选的数据，并显示更新后的卡片，请你再批准一次。

> **[待补充截图]** 一个计划的批准卡片（**Approve the plan?**），计划中用服务器裁剪从大型格点产品（例如 CMFD 或 HWSD 数据集）中截取一个小研究区：**数据** 部分中有 **批准后由 GeoForge 自动下载** 组，其中一行 `输入 ← 数据集 ID · 大小` 带有 **服务器裁剪后下载** 标签，大小是裁剪后的小尺寸（KB 或 MB）；如果有，下方还显示 **数据来源，你来选** 列表。

检查：带 **服务器裁剪后下载** 标签的那一行，大小以 KB 或 MB 为单位，而不是整个产品的大小。

### 哪个大小才算数

有两种不同的大小，只有一种是你实际要下载的：

- **整个产品的大小**：显示在目录浏览器和搜索结果里，Agent 有时也会在对话中提到。一个全国性的驱动数据产品可能有几百 GB。
- **裁剪后的大小**：显示在批准卡片上带 **服务器裁剪后下载** 标签的那一行。这才是你的项目要下载的量。在一次测试中，一份土壤图作为百度网盘下载是 1.7 GB，用服务器裁剪后只有 14 KB。

以批准卡片为准，不要信对话里说的大小。GeoForge 在显示卡片之前会再估算一次裁剪大小，你点击 **Approve and start**（批准并开始）时还会再估算一次。如果裁剪结果明显变大、数据源版本变了或者估算失败，卡片会连同原因重新显示，你需要再批准一次。批准计划就同时批准了其中的服务器裁剪，没有单独的数据批准步骤。

> **注意：** 0.6.54 的已知问题。**数据来源，你来选** 列表可能和 **数据** 部分里的数据集不一致，而且目录以外的数据源（例如 NASA POWER）不会出现在这个列表里。**等待你处理** 下面可能仍有一行写着 “defaults to NASA POWER unless you pick another”（默认用 NASA POWER，除非你另选）。批准之前，请核对 **数据** 部分里 ← 后面的数据集 ID 是不是你想要的。如果不一致，选择 **Modify the plan**（修改计划），并写明你想用的数据源。

## 3.7 已批准的数据如何送达

你批准计划后，GeoForge 会先把所有已批准的输入准备好，然后才运行任何模型步骤。送达方式有三种。

| 送达方式 | 由谁完成 | 大小上限 | 如何检查 |
|---|---|---|---|
| **直接下载** | GeoForge | 每个文件最多 100 MB | 用服务器提供的 SHA-256 校验和（相当于文件内容的“指纹”）比对文件，不一致就重新下载一次。ZIP 文件会被安全解压；含有不安全路径的压缩包会被拒绝。 |
| **服务器裁剪** | GeoForge | 每次裁剪最多 2 GB，并且磁盘剩余空间足够 | 每个部分都要和任务清单里的大小和校验和逐一核对。比估算大很多的裁剪结果会被拒绝。 |
| **百度网盘手动下载** | 你 | 无 | GeoForge 记录你放进去的文件及其指纹。百度网盘文件没有服务器校验和。 |

只要 GeoForge 保持打开，即使你关闭了 **项目状态** 或切换到别的对话，自动下载也会继续进行。等待百度网盘文件不会耽误自动下载。

> **注意：** Windows 0.6.54 版本的已知局限：这个版本发布时，真实的 GeoForge 数据库下载（直接下载、服务器裁剪和百度网盘）还没有在 Windows 上做过完整的端到端测试。如果本节的某些内容在 Windows 上表现不同，请报告给我们。

### 在对话中查看进度

准备数据时，输入框上方会出现一个横幅。它的标题告诉你正在进行哪种送达：

| 横幅标题 | 含义 |
|---|---|
| **数据准备 · 正在获取已批准的数据** | 只有自动下载在进行。 |
| **数据准备 · 需要手动下载** | 只有百度网盘下载在等你处理。 |
| **数据准备 · 自动获取与手动下载分别进行** | 两种同时进行。 |
| **已获取批准的数据 · 运行尚未开始** | 数据都到齐了，模型还没开始运行。 |
| **已获取批准的数据 · 需要先配置软件** | 数据都到齐了，但要先配置模型软件。 |

每项自动输入各占一行，例如“自动: `数据集 ID` — 服务器正在裁剪”。常见状态有 **服务器排队中**、**服务器正在裁剪**、**裁剪就绪，待下载**、**正在下载并校验**、**文件已获取** 和 **获取失败**。每项百度网盘输入各占一行“需要你手动下载: `数据集 ID`”。

横幅上的 **项目状态** 按钮会打开项目状态面板。

如果最后一项输入在某一轮对话中到达（例如你点击了 **文件已放好，继续** 之后），运行会在这一轮里继续。如果它在后台到达，横幅标题会变成 **已获取批准的数据 · 运行尚未开始** 或 **已获取批准的数据 · 需要先配置软件**。这时模型会等你点击 **开始已批准的运行**。

> **[待补充截图]** 一个已批准计划在获取数据时的对话底部，计划含一个服务器裁剪数据集和一个百度网盘数据集：横幅标题为 **数据准备 · 自动获取与手动下载分别进行**，一行“自动: … — 服务器正在裁剪”，一行“需要你手动下载: …”，以及 **项目状态** 按钮。

检查：横幅上每项输入各有一行；自动下载那一行的状态会变化，手动下载那一行保持等待。

服务器裁剪任务也列在 **项目状态 → 更多细节 → GeoForge 数据库下载任务** 中，状态包括 **服务器排队**、**服务器裁剪中**、**裁剪完成，待下载**、**下载与校验中** 和 **文件已取得；科学检查待做**。裁剪结果就绪后，GeoForge 会自己下载。如果某个任务显示 **下载失败，可重试**，点击它下面的 **下载并校验全部文件**。

### 自己从百度网盘下载

有些数据集太大，无法直接提供，也没办法按你的研究区裁剪。对这类数据，**项目状态** 里会显示一张标题为 **需要你处理** 的卡片，卡片上写着 “Download 1 dataset from Baidu Pan”（从百度网盘下载 1 个数据集；有多个时写作 “Download N datasets from Baidu Pan”）。这行文字以英文显示。对话里只会提示你去 **项目状态** 查看：链接和提取码从不在对话中显示。

卡片的每一行显示：

- 数据集名称和大小；
- **提取码**：百度网盘要求输入的码；
- **分享内只需下载**：只需要大分享中的某一个文件或文件夹时才显示；
- **放置到**：存放这些文件的确切项目文件夹，旁边有 **复制路径** 按钮；
- **打开下载链接**：打开百度网盘的分享页面。

> **[待补充截图]** 批准一个含一个手动下载数据集的计划后，**项目状态** 中的百度网盘卡片：标题 **需要你处理**，卡片上写着 “Download 1 dataset from Baidu Pan”；一行显示数据集名称和大小、**提取码**（请把提取码打码）、**分享内只需下载**、**放置到**（路径以 `inputs\observations\<dataset ID>` 结尾）和 **复制路径** 按钮、**打开下载链接**；以及 **文件已放好，继续** 和 **修改计划** 两个按钮。

检查：**放置到** 的路径以你的数据集 ID 结尾。

1. 点击 **打开下载链接**。分享页面会在你的网页浏览器中打开。
2. 输入 **提取码** 后面显示的码。
3. 如果卡片上显示 **分享内只需下载**，就只下载那个文件或文件夹；否则下载整个分享。
4. 等下载完全结束。
5. 点击 **放置到** 旁边的 **复制路径**。按钮会变成 **已复制**。
6. 打开 **放置到** 所指的文件夹：

    - **Windows：** 把路径粘贴到文件资源管理器的地址栏，按 Enter。
    - **macOS：** 在访达中选择 **前往 → 前往文件夹…**，粘贴路径，按 Return。

7. 如果文件夹还不存在，就新建一个，名称必须和路径最后一段完全一致（也就是数据集 ID）。
8. 把下载的文件移动或复制到这个文件夹。不要把它们留在百度网盘的下载文件夹里。
9. 等复制完成。
10. 在 **项目状态** 中点击 **文件已放好，继续**。

GeoForge 会关闭 **项目状态**，并在对话中发送“我已把 … 放到 …，请继续。”（如果对话还在处理，这条消息会留在输入框里，等你发送。）然后 GeoForge 会为文件夹中的文件计算指纹，并为它们签署一份运行记录。如果文件夹里还没有可用的文件，卡片会保持打开。

> **注意：** GeoForge 会忽略还在写入的文件（文件名以 `.part`、`.crdownload`、`.tmp`、`.bc!` 等结尾）、以点开头的文件，以及符号链接。请在下载和复制都完成之后，再点击 **文件已放好，继续**。

如果不方便下载，点击 **修改计划**。输入框里会填入“请修改计划：”。把这句话补完整，例如要求改用公开数据源，或者说明你可以提供自己的文件，然后发送。修改后的计划需要重新批准。

> **提示：** 在中国大陆以外，百度网盘常常很慢，甚至用不了。如果你无法使用百度网盘，请向 GeoForge 数据库管理者询问其他获取文件的方式，或者点击 **修改计划**。

### 已批准的下载失败时

GeoForge 会停下来，在对话中显示一张标题为 “Some approved data could not be fetched”（部分已批准的数据无法获取）的卡片，列出每一项失败。对话中会显示 “Some approved data could not be fetched. Use the card in the chat to retry or modify the plan.”（请用对话中的卡片重试或修改计划）。这张卡片的标题和选项以英文显示。

1. 在卡片上选择一项：

    - **Retry the missing data**（重新获取缺失的数据）：只重新获取失败的项目。已经检查过的文件会保留。
    - **Modify the plan**（修改计划）：把计划连同你的说明退回给 Agent。

2. 点击 **按此选择继续**。

## 3.8 数据存放在哪里，运行记录能证明什么

所有内容都保存在你的项目文件夹里。下面的例子中，项目文件夹是 `D:\GeoForge-Manual\projects\2026-10-01-huai-test--…`。路径中的 `<dataset ID>` 指数据集 ID，`<acquisition ID>` 指下载任务的 ID。

| 内容 | 在项目中的位置 |
|---|---|
| 直接下载的文件 | `inputs\observations\<dataset ID>\` |
| 你放进去的百度网盘文件 | **放置到** 所指的文件夹，通常是 `inputs\observations\<dataset ID>\` |
| 服务器裁剪结果 | `inputs\geoforge_subsets\<acquisition ID>\` |
| 直接下载的原始 ZIP 压缩包 | `.geoforge\downloads\` |
| 数据的签名运行记录 | `.geoforge\receipts\data-receipts\` |

`.geoforge` 文件夹由 GeoForge 使用。macOS 的访达会隐藏它；Windows 的文件资源管理器会显示它。不要编辑或删除里面的任何内容。

GeoForge 带进来的每项输入都有一份签名的运行记录（界面里叫 receipt）。**项目状态** 中的 **本次计划的数据** 根据这些记录和磁盘上的文件来判断状态，而不是根据 Agent 的说法：

| 状态 | 含义 |
|---|---|
| **尚未准备** | 还没有获取或准备。 |
| **等你处理** | 百度网盘下载或需要你提供的文件还缺着。 |
| **已下载，待科学检查** | 数据已到，并且有签名的运行记录。 |
| **文件存在，尚未核实** | 文件在文件夹里，但没有运行记录覆盖它们。 |
| **下载失败** | GeoForge 没能获取这一项。 |
| **计划中未用到** | 计划列出了这一项，但没有任何步骤用到它，所以不会去获取。 |

> **[待补充截图]** 一个含一个直接下载、一个服务器裁剪和一个百度网盘数据集的计划，在获取完成后的 **项目状态 → 本次计划的数据**：**GeoForge 自动下载** 组中各行 `输入 ← 数据集 ID · 大小` 的状态为 **已下载，待科学检查**；点击 **文件已放好，继续** 后，**需要你处理** 组中的百度网盘那一行也是同样状态；以及提示“来自已批准/已提交的数据清单；状态由 receipt 和本地文件决定，不是 Agent 的说法。”

检查：每项数据库输入都显示 **已下载，待科学检查**。

如果你删除或替换了下载的文件，它就不再算作已获取。修改计划时，如果同一个数据集请求保持不变，已检查过的下载会被复用，同样的数据不会下载两次。

数据的运行记录能证明什么，不能证明什么：

| 送达方式 | 记录能证明 | 记录不能证明 |
|---|---|---|
| 直接下载 | 文件与服务器的校验和一致，并且来自已批准的请求。 | 数值正确，或者适合你的模型。 |
| 服务器裁剪 | 每个部分都与服务器任务的大小和校验和一致。 | 裁剪结果按你的意图覆盖了研究区；范围请自己检查。 |
| 百度网盘 | 你放进去的是哪些文件，以及它们的指纹。 | 这些文件与原始文件一致；百度网盘文件没有服务器校验和。 |

下载的数据不等于经过检验的科学数据。模型运行前，KI 仍会准备并检查输入（单位、范围、数值）。GeoForge 保证的是：项目标记为 **已完成** 之前，每个已批准的步骤都有签名的运行记录。**已完成** 并不代表结果在科学上已经验证；判断结果仍然是你的工作。

## 3.9 隐私

**Token 只留在你的电脑上。** 它不会写入设置文件、项目文件夹、对话记录或日志，也不会发给 Agent。设置页面上只显示圆点。

| | Windows | macOS |
|---|---|---|
| Token 存放位置 | 凭据管理器中的普通凭据 `com.geoforge.desktop:observation-activation-token` | 只有你的用户账户能读取的私有文件：`~/Library/Application Support/KISS/secrets/com.geoforge.desktop.observation-activation-token` |
| 目录副本存放位置 | `%APPDATA%\KISS\database\catalogue.json` | `~/Library/Application Support/KISS/database/catalogue.json` |

在 Windows 上，你可以在 **控制面板 → 凭据管理器 → Windows 凭据** 的 **普通凭据** 下查看或删除已保存的 Token。如果在那里删除了它，请重启 GeoForge（托盘图标 → **Exit GeoForge**（退出 GeoForge），然后重新启动）。托盘菜单以英文显示。必须重启，因为正在运行的 GeoForge 会继续使用它已经读取的 Token。

**Agent 看到的是搜索结果，不是 Token。** API 类 Agent 收到的是清理过的数据集描述。CLI 类 Agent（例如 Claude Code、OpenAI Codex 或 Kimi Code）收到的是一张临时的只读通行证，只能访问 GeoForge 自己的本地服务。它只允许目录搜索、读取数据集字段和裁剪估算，GeoForge 关闭后就失效。

**百度网盘链接只给你一个人看。**

- 链接和提取码只在 **项目状态** 中显示给你，不会给 Agent，也不会出现在对话里。
- 服务器每给出一个链接，都会记在你的 Token 名下。已经给出的链接无法收回。
- 为了让卡片在重启后还在，GeoForge 会把链接保存在项目文件 `.geoforge\manual-download-details.json` 中。

> **注意：** 如果项目文件夹里还有 `.geoforge\manual-download-details.json`，不要分享或公开这个文件夹。在你要分享的副本里删掉这个文件。

## 3.10 遇到问题时

数据库服务器返回的消息以英文显示。**保存并测试数据库** 的结果显示在 Token 输入框下方的提示里。

| 你看到的 | 含义 | 怎么做 |
|---|---|---|
| “Paste your activation token in Settings.” | 没有保存 Token。 | 填入你的 Token（见 3.3 节）。 |
| “That token isn't right — check for a copy/paste miss.” | 服务器不认这个 Token。 | 重新复制完整的 Token，不要带空格或换行。按 3.3 节的方法替换，然后点击 **保存并测试数据库**。 |
| “Your token expired — ask the group owner for a new one.” | Token 已超过 6 个月。 | 重新申请 Token（见 3.2 节）。 |
| “This token was revoked — ask the group owner.” | 管理者收回了这个 Token。 | 联系管理者（见 3.2 节）。 |
| 状态标签为 **不可用**，并显示“访问不可用：当前 Token 未获授权……” | 上一次刷新时，服务器拒绝了已保存的 Token。 | 粘贴有效的 Token，点击 **保存并测试数据库**。如果你几秒前刚保存过 Token，先等一分钟，再重新打开页面。 |
| “Daily download limit reached; resets at midnight server time.” | 你的 Token 今天已经用掉 20 GB 或 2,000 次请求。 | 等服务器时间过了午夜，再点击 **Retry the missing data**。 |
| “GeoForge could not reach GeoForge Database.”，或者状态标签为黄色的 **已连接**，并带有“· 已过期：…” | GeoForge 没有联网，或者代理线路不对。 | 搜索仍可使用本地目录。读取数据集字段、裁剪估算和下载要等联网后才能进行。检查网络和下面的代理设置，然后点击 **保存并测试数据库** 刷新。 |
| 以 “GeoForge Database server or gateway” 开头的消息（例如 “…returned HTTP 502” 或 “…is unavailable”） | 问题出在服务器端。 | 稍后再试。不要因为这个原因把计划改成手动下载。 |
| 提到 Credential Manager 的消息（Windows），例如 “Credential Manager write failed (…)”；或提到 “the private token file” 的消息（macOS） | GeoForge 无法在系统密码存储中读取或保存 Token。状态标签可能显示 **未配置**。 | 重启 GeoForge，再点击一次 **保存并测试数据库**。在 Windows 上，检查能否从控制面板打开凭据管理器。 |
| “The catalogue is being fetched; try again in a moment.” | 第一次目录下载还在进行。 | 等一分钟，再重新打开 **设置 → GeoForge 数据库**。 |
| 提示一直停在“正在保存并测试数据服务……” | 另一个设置页面里有无效的值，所以什么都没有保存。错误信息显示在窗口底部 **保存** 旁边（例如 “proxy address is required in manual mode”）。 | 修正那个页面（例如在 **网络与代理** 中填入代理地址），然后再点击 **保存并测试数据库**。 |
| 测试成功后，状态标签或数据集列表没有变化 | 页面不会自动刷新。 | 点击 **关闭**，打开 **设置**，再点击 **GeoForge 数据库**。如果列表仍然是空的，就重新加载：Windows 上在 GeoForge 的浏览器标签页中按 F5；macOS 上退出并重新打开 GeoForge。 |
| 搜不到你想要的数据 | 目录内容是英文的，而且设置页的搜索框按你输入的原样匹配。 | 用一个英文单词、站号或数据集 ID 搜索。 |
| 批准被拒绝，并显示 “GeoForge Database access is off or not activated…” | 计划需要数据库，但数据库没有激活。 | 激活数据库（见 3.3 节）后重新批准，或者选择 **Modify the plan**，改用公开数据源或你自己的文件。 |
| 点击 **文件已放好，继续** 后，百度网盘卡片仍然没有关闭 | GeoForge 在 **放置到** 文件夹中没有找到可用的文件。 | 确认文件就在这个文件夹里，下载和复制都已完成，文件名不以点开头。然后再点一次这个按钮。 |
| “… already holds files with no receipt …” | 目标文件夹里已有 GeoForge 无法说明来源的文件。没有覆盖任何文件。 | 把这些文件移出文件夹，再点击 **Retry the missing data**；或者选择 **Modify the plan**，把它们作为你自己的输入。 |
| “The downloaded file failed integrity verification twice.” | 文件与服务器的校验和不一致。 | 点击 **Retry the missing data**。如果再次出现，请报告给数据库管理者。 |
| “The downloaded archive contains an unsafe path.” | 出于安全考虑，GeoForge 拒绝了一个 ZIP 文件。 | 报告给数据库管理者，并选择 **Modify the plan**。 |
| “Insufficient local disk space for the complete verified acquisition” | 磁盘剩余空间不够放服务器裁剪结果。 | 在存放项目的磁盘上腾出空间，再点击 **Retry the missing data**。 |
| **裁剪估算记录**（在 **GeoForge 数据库下载任务** 中）里的某一条显示 **裁剪估算失败；尚未确认可取数** | 服务器无法估算这次裁剪。没有创建任务，也没有下载任何东西。 | 在对话中请 Agent 重新估算裁剪。如果消息里提到未知的源变量，请它先读取数据集字段，再用准确的变量名重新估算。不要让它去掉变量筛选。 |
| Agent 说某个数据集“不可用”，原因是它要从百度网盘下载 | 手动下载是正常途径，不代表数据集缺失。 | 如果这个数据集适合你的研究，告诉 Agent 保留它；否则选择别的数据源。 |

> **注意：** 如果你把有效的 Token 换成了错误的 Token，测试会报错，但状态标签可能在最多 6 小时内（直到下一次目录刷新）仍显示 **已连接**。请以 Token 输入框下方的提示为准，并重新粘贴正确的 Token。

> **提示：** Agent 可能引用的过期警告里写着 “Refresh explicitly in Settings”（请在设置中手动刷新）。设置里没有单独的刷新按钮：要强制刷新，就点击 **保存并测试数据库**。

### 代理设置与数据库

数据库的网络请求遵循 **设置 → 网络与代理** 中的设置。

1. 点击左侧边栏底部的 **设置**。
2. 点击 **网络与代理**。

![网络与代理页面，已勾选观测数据服务](../../images/zh-CN/04-settings-net.png)

检查：在 **以下服务使用代理** 下，**观测数据服务** 已勾选。它默认就是勾选的。

- 勾选 **观测数据服务**：数据库请求使用 **代理** 下选择的代理。
- 不勾选 **观测数据服务**：数据库请求直接连接，不使用任何代理。
- **手动输入代理**：填入代理地址，例如 `http://127.0.0.1:7897`。代理密码不会保存。
- **不使用代理**：所有请求都不走代理。

| | Windows | macOS |
|---|---|---|
| 第一个代理选项 | 显示为 **使用 Mac 系统代理（推荐）**，但实际使用的是 Windows 系统代理。 | **使用 Mac 系统代理（推荐）** 使用 macOS 系统代理。 |

如果不开 VPN 时数据库正常，开了 VPN 反而失败：

1. 在 **网络与代理** 页面，取消勾选 **观测数据服务**。
2. 点击 **保存**。
3. 在设置菜单中点击 **GeoForge 数据库**。
4. 点击 **保存并测试数据库**。

百度网盘下载是在你自己的浏览器或百度网盘客户端里进行的，所以 GeoForge 的代理设置不影响它们。
