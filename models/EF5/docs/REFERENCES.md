# EF5 — References and Documentation

## Source Code
- **GitHub repository**: https://github.com/HyDROSLab/EF5
- **Authors**: Zac Flamig, Humberto Vergara, Race Clark, JJ Gourley, Yang Hong
- **Institution**: HyDROSLab, University of Oklahoma / NOAA NSSL

## Key Publications

1. **Flamig, Z.L., Vergara, H., and Gourley, J.J. (2020).** "The Ensemble Framework For Flash Flood Forecasting (EF5) v1.2: Description and Multi-Scale Evaluation." *Geoscientific Model Development*, 13, 4943-4958. https://doi.org/10.5194/gmd-13-4943-2020

2. **Clark, R.A., Flamig, Z.L., Vergara, H., Hong, Y., Gourley, J.J., Mandl, D.J., Frye, S., Talbot, M., and Argon, I. (2017).** "Hydrological Modeling and Capacity Building in the Republic of Namibia." *Bulletin of the American Meteorological Society*, 98(8), 1697-1715.

3. **Vergara, H., Kirstetter, P.E., Gourley, J.J., Flamig, Z.L., Hong, Y., Arthur, A., and Kolar, R. (2016).** "Estimating a-priori kinematic wave model parameters based on regionalization for flash flood forecasting in the Conterminous United States." *Journal of Hydrology*, 541, 421-433.

## External Data Sources
- **HWSD**: Harmonized World Soil Database (FAO/IIASA) — soil parameters
- **STATSGO**: State Soil Geographic Database (USDA/NRCS) — US soil parameters
- **CMFD**: China Meteorological Forcing Dataset — precipitation, PET, temperature
- **MSWX**: Multi-Source Weighted-Ensemble Precipitation
- **MRMS**: Multi-Radar Multi-Sensor — US high-resolution QPE
- **TRMM**: Tropical Rainfall Measuring Mission — global precipitation
