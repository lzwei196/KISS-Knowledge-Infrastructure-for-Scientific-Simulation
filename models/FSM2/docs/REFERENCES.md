## Key Publications

1. Essery, R. (2015). A Factorial Snowpack Model (FSM 1.0). *Geoscientific Model Development*, **8**, 3867-3876. doi:10.5194/gmd-8-3867-2015

2. Essery, R., Mazzotti, G., Barr, A., Jonas, T., Quaife, T. and Rutter, N. (2025). A Flexible Snow Model (FSM 2.1.1) including a forest canopy. *Geoscientific Model Development*, **18**, 3583-3605. doi:10.5194/gmd-18-3583-2025

## Validation Reference Data

- **Alptal, Switzerland (2004-2005)**: ESM-SnowMIP site used for example validation. Subalpine coniferous forest with open and forested points.
  - Reference: Stahli, M. and Gustafsson, D. (2006). The role of snow interception in winter-time radiation processes of a coniferous sub-alpine forest. *Hydrological Processes*, **23**, 2498-2512.

## Related Projects

- **ESM-SnowMIP**: Earth System Model Snow Model Intercomparison Project — provides standardized forcing and evaluation datasets for snow models.
- **SNOWMIP2**: Earlier snow model intercomparison that included factorial experiments.
