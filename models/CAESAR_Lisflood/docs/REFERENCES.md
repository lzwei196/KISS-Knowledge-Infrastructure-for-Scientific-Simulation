## Related Models

- **LISFLOOD-FP**: 2D hydraulic model providing the flow routing algorithm (University of Bristol)
- **TOPMODEL**: Semi-distributed rainfall-runoff model providing subsurface flow component (Beven & Kirkby, 1979)
- **CAESAR**: Original cellular automaton landscape evolution model (Coulthard et al., 2002)
