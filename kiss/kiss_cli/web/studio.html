Four separate decisions
Workbench draft: KDT and the Agent have produced an editable KI candidate.

User accepted: only your explicit decision adds that snapshot to the KI Library.
Verified software: later, the Setup Agent runs the KI's real preflight on this computer. Authoring verification never claims the scientific software already runs.
